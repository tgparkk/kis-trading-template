**한계**

1. 🔴 **`news.created_at` 시간대 결함(측정 전 발견 · 사전등록 F1)**: 저장값 2026-03-09 12:00 이전 행은 UTC 로 적혀 있다(서버는 Asia/Seoul). 규칙(`< 2026-03-09 12:00`) 과 「소수초 0」 지문이 연결 519,551행에서 완전히 일치(UTC 418,370 · KST 101,181 · 불일치 0)하고, 비-dart 출처의 `created_at − published_at` 중앙값이 UTC 구간 −8.4~−9.0시간 · KST 구간 ≈ 0 으로 독립 확인됨(검증 직원 09-30). 이 연구는 +9시간 보정했다. **보정 없이 이 구간을 쓴 다른 연구·shadow 는 개장 전 창에 장중·장후 기사가 섞였을 수 있다** — 관리자가 인용한 「지연 중앙 2분·p90 213분」도 어느 구간에서 잰 값인지 확인 필요.
2. **뉴스 커버리지 공백**: 비-dart 기사 종목 연결은 2026-02-10~08-17 사실상 0 · 2025-12 는 시황 기사가 기사당 수십 종목에 연결돼 있었다. 그래서 N1 은 「연결 ≤ 3 기사」 + 커버 55일로 좁혔고(적격 연결 24,186 / 비-dart 연결 423,202), 이것이 N1 표본 84건의 원인이다.
3. **본문·제목 미사용**: 기사 «있음/없음»만 봤다(본문은 출처별 잘림). 호재/악재 방향은 모른다 — 방향이 섞이면 평균 차이는 0 쪽으로 끌린다.
4. **D 당일 공시 제외**: `rcept_dt = D` 는 접수 시각이 없어 뺐다. 반대로 `rcept_dt = D−1` 에는 장중(09:00~15:30) 접수도 들어가 전일 종가에 이미 일부 반영됐을 수 있다. 시각이 있는 공시 피드(N2b · 2026-01-08~ · 164일)로 본 탐색도 같은 모양(r_oc 없음 · r_c1 판별 보류).
5. **DART 범위**: `dart_disclosures` 는 주요사항보고(B)·거래소공시(I) 두 유형만 적재돼 있다(정기·지분·발행공시 없음). N2 = 「B·I 공시」.
6. **해외 파트너 동조**: 미국↔국내 종목 매핑표가 없어 **측정 밖**. **N3 섹터 뉴스**: 미측정.
7. **생존편향·자료 공백**: 유니버스는 `daily_prices` 에 있는 종목뿐이고, D+1·D+5 행이 없으면 그 결과만 결측(E5 r_c5 결측 83건). 상장폐지·거래정지 종목의 결측은 양 군에 대칭이라고 가정했다(검증 안 함).
8. **분할 필터의 사각**: `adj_factor` 가 2026-06 부터 대부분 NULL 이라 U5 는 6~9월에 거의 작동하지 않는다. ±30% 위생 필터(U6)가 E5 23건을 추가로 뺐다. 기준가 변경이 ±30% 안에 숨으면 못 잡는다.
9. **U5·U6 는 D..D+5 를 본다**(자료 유효성 필터 · 양 군 대칭). 결과를 보고 고른 필터는 아니다(사전등록 §3).
10. **클러스터 수**: N1 비교의 정보 날짜 33일 — 날짜 부트스트랩이 가능한 하한 근처다.

## §5 다음 할 일 제안

1. **`news.created_at` UTC 구간 결함을 데이터 백로그에 올리고, 뉴스 시각을 쓴 기존 연구(09-14 뉴스 사전등록 2건 등)가 2026-03-09 이전 구간을 보정 없이 썼는지 점검**. 이번 연구 결론과 무관하게 공통 결함이다.
2. **「갭 뒤 하락」은 유동성 문제일 수 있다**(탐색 X14: 07-01~09-30 갭 ≥ +5% 가 거래대금 필터 없음 −2.38% → 10억 이상 −0.01%). 갭 관련 룰을 논의한다면 재료보다 **거래대금 분리를 새 사전등록으로** 먼저 재는 것이 순서다.
3. **뉴스 조건(N1) 재검정은 표본이 쌓인 뒤**. 8~9월 커버 30일에 N1 있는 갭 38건 속도로는, MDE 를 1%p 로 줄이는 데 필요한 n1 ≈ (2.8016 × 8.21 / 1.00)² ≈ 530건까지 400거래일 넘게 걸린다(n0 ≫ n1 근사 산수). 뉴스 종목 연결 품질(연결 ≤ 3 기사 비율) 개선이 선행 조건.
