### 2-1. 왜 「코드 1줄」이 아니라 「설정 1줄」인가

`config/constants.py:269-288` 이 env 문자열을 해석한다:

- 빈 값 / 미설정 → **`shadow`**(기본값)

⇒ 발효는 **git diff 가 아니라 프로세스 환경**으로 일어난다. 그래서 리뷰는 코드 리뷰가 아니라 **설정 변경 검증**이다.

## ⑤ 반증 조건 · 「효과 없음으로 읽지 않는 구간」

### 5-1. 반증 → 행동

| 반증 | 의미 | 행동 |
|---|---|---|
| **P1 불성립** (`kept ≠ matched − flagged`) | 배제가 계약대로 안 돈다 | **즉시 롤백**(§⑥) |
| **P2 ≥1건** | live 인데 오염 종목을 샀다 | 롤백 + 배선 결함 조사(스크리너 경로 vs `on_tick` 경로) |
| **P3 < 5건** | 가드가 실제로 걸릴 일이 거의 없다 | **`off` 복귀 검토**(자동 롤백 아님 · 사장님 판단) |
| **P4 중앙값 < 0.5** | 탐지기가 날마다 다른 집합을 고른다 | **별건 등재** — 이 결정의 롤백 사유가 아니다 |
| 기동 줄 `mode=live` 부재 | `.env` 가 프로세스에 안 닿았다 | 발효 **미성립**. 관측일로 세지 않는다 |
| 기동 줄 `mode=off` + INVALID WARNING | 오타로 `off` 강등됨(`constants.py:288` 규약) | 발효 **미성립**. `.env` 값 수정 후 재기동 |

### 5-2. 🔑 효과 없음으로 읽지 않는 구간

- **flagged = 0 인 날**: 그날은 P1 이 자명하게 성립(0−0)하고 P3 가 늘지 않는다.
  이것은 **「가드가 무효」가 아니라 「그날 오염 후보가 없었다」**이다. P3 분모에서 제외하지 않되, **단독으로 off 근거로 쓰지 않는다.**
- **rs_leader 매수 신호 0 인 날**: P2·P3 의 **판정 불가**일이다. 「효과 없음」으로 읽지 않는다.
- **캡(`max_positions`) 포화일**: 체결이 캡에 묶여 배제 효과와 분리되지 않는다.
  P3 의 「회피 체결」은 **후보 단계**에서 세므로 영향이 작지만, 체결 건수 축은 **지표로 쓰지 않는다.**
- **성과 축(수익률·승률·손익)**: **어느 방향으로도 판정 근거가 아니다**(R3). 악화돼도 「가드가 나쁘다」로 읽지 않고,
  개선돼도 「가드가 좋다」로 읽지 않는다. §⑦ 대로 **보고만** 한다.

## ⑥ 롤백


   그런데 `screener_snapshots` 는 **전 날짜 정확히 20행**이라 21위 이하가 DB 에 없다.
   ⇒ 「배제 안 했다면 누가 올라왔을까」의 완전 반사실은 **원리적으로 구성 불가**다.
   🟢 다만 09-15 실측으로 **구조적 사실 1건은 확정**됐다 — 대체 1·2순위(`017900`·`079650`)가
   **쿨다운과 무관하게** `[매수거절] 진입가 밴드 이탈`(D-1 종가 ×1.03 상한)로 거절됐다.
   ⇒ **배제한 자리가 곧바로 다른 종목으로 채워지지는 않는다**(RS 상위는 이미 오른 종목이라 밴드에 더 자주 걸린다).

2. **DART 커버리지 8/11 은 «검색 한계»이지 오탐률이 아니다.**
   주식병합·액면병합은 **KRX 변경상장 공시**이고 DART 에는 「감자결정」·「주식병합 결정」으로 다른 이름으로 올라간다.
   병합 키워드로 감자를 못 잡는 건 당연하다. 또한 `corp_action_refetch_queue.jsonl` 의 status 는 **전부 `pending`**
   ⇒ **정답지(수동 재수집 결과)가 없다.** 8/11 은 **DART 사건 존재**이지 **재수집 검증이 아니다.**

3. **손실 크기 검정은 무효다 — 그대로 기록한다.**

   | 축 | 통계량 | 판정 |
   |---|---|---|
   | 원화 손익(큐 118 vs 비큐 42) | **U = 2,295 · z = −0.710 · p ≈ 0.48** · 중앙값 −58,176 vs −57,945(**비 1.004×**) | **유의하지 않음** |
   | 손실건만(82 vs 29) | U = 1,079 · z = −0.738 · p ≈ 0.46 | 유의하지 않음 |
   | **%수익률**(MWU) | **z = −0.054 · p = 0.957** · CLES 0.497 · 중앙값 −8.04% vs −8.10% | **완전 무효** |
   | 부트스트랩(B=20,000) 평균차 95%CI | **[−6.74%p, +1.36%p]** · 종목 클러스터 보정 [−7.05, +1.45] | **0 포함** |
   | 최악 손실 8건이 8/8 큐 | naive p ≈ 0.0875(n=8 · 사후 선택 꼬리) | 유의하지 않음 |

   ⇒ 3세션 연속 보고돼 온 「큐 종목 건당 손실 2.33× → 2.72× → 2.44×」는 **분포의 차이가 아니라 꼬리 몇 건의 산술**이다.
   ⇒ **성과 논거는 죽었다.** 이 전환은 **위생 논거 하나로만** 선다(§③ · R3).

4. **매도 건 비독립성.** 같은 종목 반복·같은 날 군집이라 위 검정의 유효 n 은 명목보다 작다.

5. **부수 관측(단정 금지 · 레인 B 사안).** `024850`·`053950`·`184230` 은 정지 전 행에 `adj_factor=0.2` 가
   찍혀 있는데 가격이 역조정되지 않았다 ⇒ 「가격은 이미 조정 저장」이라는 읽기계층 전제가 이 행들에선 깨진다.
   나머지 8종목은 `adj_factor` 가 NULL/1 이라 팩터조차 없다. 여기선 **관측만 남긴다.**

6. **정지 구간 패딩.** 정지 구간 종가가 직전 종가로 통째 패딩돼 있다(`184230` 754×9봉 · `285800` 733×14봉 ·
