## 2. 후보 도구 — 세 부품 🔒

**(P1) 종목 클러스터 순열** — 교환 단위 = **(전략 × 종목) 블록**(같은 전략 안 같은 종목의 모든 행).
- 전략 s 안에서 블록 크기(행 수) **5분위 층** 안에서만 블록을 무작위 순열 π 로 짝짓는다(크기 정합).
- 블록 g 는 π(g) 블록의 라벨열을 **scan_date 순서 그대로** 받는다. 길이가 다르면 원형 반복(짧을 때) / 앞에서 절단(길 때).
- 종목 상수 특징에서는 이것이 정확히 「종목→값 매핑 섞기」와 같다. 결과 열(`ret_pct`)은 움직이지 않는다.

**(P2) 에피소드 단위 SE** — 에피소드 = 같은 전략·종목의 **연속 거래일 scan_date 묶음**(B 의 `ep_first` 정의와 동일).
- 대표값 = **첫 행(주)** · 에피소드 평균(병기 · 인쇄만).
- 🔒 `features.csv` 의 `ep_first` 열은 **C 창에만** 계산돼 있다(`feature_study/run_features.py:386-389` · E 는 전부 False) ⇒ **이 열은 쓰지 않는다.** E·C 모두 **같은 식**(전략×종목을 달력 순번 `cal_i` 로 정렬 · 직전 행과 순번 차 > 1 이면 새 에피소드)으로 **다시 계산**한다.
- `Δ_s` 의 SE = 에피소드 표본에서 **종목 클러스터 로버스트(CR1) 분산** — 같은 종목의 여러 에피소드는 한 클러스터. `p = 2·Φ(−|Δ_pool| / SE_pool)`.

**(P3) 날짜 안 분위** — 분위를 창 전체가 아니라 **(전략, scan_date) 안**에서 매긴다(`rank(pct=True, method='average')` · T1 ≤ 1/3 · T3 > 2/3).
- 그날 비결측 행 < 3 인 날은 제외하고 건수를 인쇄한다. 날짜 간 성분(국면)이 Δ 에서 빠지므로 **문턱과 p 가 같은 것을 잰다**(퀀트 §2-2 · 패널 ①-11).

## 3. 평가할 조합 · 우선순위 🔒

| 순위 | 조합 | 분위 | 귀무 / SE |
|---|---|---|---|
| **K1** | P3 + P1 | 날짜 안 | 종목 클러스터 순열 |
| **K2** | P3 + P2 | 날짜 안 | 에피소드 첫 행 · CR1 |
| **K3** | 창 전체 + P1 | 창 전체(B 와 같음) | 종목 클러스터 순열 |
| **K4** | 창 전체 + P2 | 창 전체 | 에피소드 첫 행 · CR1 |
| 대조 K0 | B 원 도구 | 창 전체 | `(strategy, scan_date)` 블록 순열 — **재현 확인용**(V-F5 0.34 가 다시 나오는지 · 판정 대상 아님) |

- 🔒 **주 도구 = 합격한 조합 중 위 순위가 가장 높은 것 하나.** 검정력(MDE)으로 고르지 않는다(가짜 특징을 보고 고르는 자유도를 없앤다).
- 🔒 **확정 순서**: K1~K4 전부 1단계를 돌리고, 순위가 더 높은 조합이 「경계」이면 **그 2단계가 끝난 «뒤»에** 주 도구를 확정한다(낮은 순위 조합이 먼저 합격해도 기다린다).
- 순열 횟수 = **2,000회**(교정) · 10,000회(§6 재적용 인쇄). 순열 p = `(1 + #{|Δ_perm| ≥ |Δ_obs|}) / (1 + 횟수)` · 양측.

## 4. 가짜 특징 — 세 종류 × 100개 🔒

| 종류 | 정의 | 무엇을 시험하나 | 시드 |
|---|---|---|---|
| **G-종목** | 종목마다 값 1개 `x_g ~ N(0,1)`(전략·날짜 무관 상수) | 종목 연속 후보 · 보유 겹침(V-F5 와 같은 자리) | `default_rng([20261001, 1, i])`, i=1…100 |
| **G-날짜** | `x = a_d + 1e−6·u_row` · `a_d ~ N(0,1)`(날짜마다 1개 · 전 전략 공통) · `u_row ~ U(0,1)`(행마다 · 동점 깨기) | 날짜(국면) 교락 — 창 전체 분위는 `a_d` 가 지배, 날짜 안 분위는 `u` 만 남아 «행 독립 노이즈» 시험이 된다 | `default_rng([20261001, 2, i])` |
| **G-AR** | 종목별 AR(1): KOSPI 달력(2024-03-13~2026-09-23) 위에서 `x_{g,t} = 0.9·x_{g,t−1} + √(1−0.9²)·ε_{g,t}` · `ε ~ N(0,1)` · `x_{g,0} ~ N(0,1)` · 행 값 = 그 종목의 그 scan_date 값(전략 무관) | 종목 안에서 «천천히 변하는» 특징(시총·RS·거래대금형) — 종목 상수와 행 독립 사이 | `default_rng([20261001, 4, i])` |

- 순열 시드: `default_rng([20261001, 3, k, i, t])`(k = 조합 번호 0~4 · t = 가짜 종류 1 G-종목 / 2 G-날짜 / 4 G-AR). B 의 시드(20260925·20260927)와 겹치지 않게 새로 잡았다.
- 🔒 가짜 특징의 결측 = 없음(전 행에 값) · 통계량·분위·풀링은 §2~3 그대로.

## 5. 합격 기준 🔒

**통계량** = 조합별로 G-종목 · G-날짜 · G-AR 각 100개의 **풀링 검정 `p < 0.10` 거부율**(창 E) — **3종 모두** 기준을 넘어야 한다.

| 단계 | 규칙 |
|---|---|
| **1단계(100개씩)** | 세 거부율이 **모두 0.07 ~ 0.13** ⇒ **합격**. 하나라도 `< 0.04` 또는 `> 0.16` ⇒ **불합격**. 그 밖(하나 이상이 0.04~0.07 · 0.13~0.16 = 「경계」) ⇒ 2단계 |
| **2단계(경계일 때만 · 1회)** | 3종 모두 **300개씩 추가**(시드 i=101…400 · 규칙 동일) → **400개 기준 세 거부율 모두 0.07 ~ 0.13** ⇒ 합격, 아니면 불합격 |

- 🔑 2단계를 둔 이유(산술): 명목이 정확히 0.10 인 «올바른» 도구도 100개에서 한 거부율이 0.07~0.13 에 들 확률은 **75.9%**, 둘 다는 **57.6%** · 셋 다는 **43.7%** 뿐이다(이항 계산 · 독립 근사). 400개면 셋 다 **89.4%**. 0.04~0.16 은 100개 기준 이항 97% 구간이다.
- 🔒 `p < 0.05` 거부율(명목 0.05)은 **인쇄만** — 합격 판단에 쓰지 않는다.
- 🔒 전략별 거부율(전략 하나씩 돌린 Δ_s 검정)도 **인쇄만**.
- 🔒 **어느 조합도 불합격이면** ⇒ 「도구 미확정」 기록 · 후속 검정(NW1 게이트 · 청산 짝 비교 · 무작위 진입 대조군 · 후보 특징) **전부 보류 유지**. 새 도구는 **개정문을 먼저 커밋**하고 **새 시드(가짜 특징 재사용 금지)** 로 다시 시험한다. 결과 변수·표본은 B 와 동일하게 둔다.
