# N-1 수리 로드맵 — 한 장 (2026-09-03, 사장님용)

> 「어느 게 올바른 방향인지 이해하기 힘드네요」에 대한 답.
> 상세 근거는 각 링크 문서. 이 문서는 지도 한 장만 담는다.

## 1. 문제는 하나다

**DB 의 과거 주가가 주식병합(예: 10주→1주)을 반영하지 못한다.**
병합하면 주가가 10배가 되는데, 우리 DB 는 과거 가격을 안 고쳐서 그 종목이 **가짜 +3,700% 급등주**로 보인다. (= N-1 결함, 08-24 검수에서 확정)

이 하나에서 나온 증상들:

| 증상 | 무엇이 일어났나 |
|---|---|
| rs_leader 가 가짜 급등주를 산다 | 「RS 리더」 랭킹이 사실상 «병합 배율 랭킹» — 09-03 900300 매수도 이것 |
| 8/31 보정(T1 apply)이 지워졌다 | 봇이 **밤마다 최근 ~100일치를 원본 가격으로 덮어쓴다** → 창 안 보정만 삭제 → 절벽 2개 혼합 상태 → 09-02 ③ 부분 복원으로 정리 |
| 가드가 못 거른다 | 불가능봉 가드는 **하락 전용**(−35% 미만만) — 병합 «상승» 점프는 통과 (09-03 실측) |

## 2. 수리는 순서가 정해진 3단계 공사다 (누수 비유)

```
① 수도꼭지 잠그기        ② 틀린 설계도 고치기         ③ 벽지 다시 바르기
   쓰기 경로 수정      →     corp_events 049470     →     가격 재보정
   (밤마다 덮어쓰기 중단)      (계수 10.0 → 1.175)          (T1 재적용 + 3종목 재편입)
```

- **①이 먼저인 이유**: ③을 먼저 하면 밤에 또 지워진다 — **이미 8/31~09-01 에 실제로 겪었다.**
- **②는 예외적으로 지금 가능**: 049470 의 병합은 2024년이라 «최근 100일 창 밖» ⇒ ① 없이도 지워지지 않는다. 문서도 이미 verifier 2패스 통과로 대기 중.
- 8/25 전문가 자문 순서 「계기→안전장치→**데이터**→룰」의 데이터 단계가 바로 이 공사다.

- **900300 지금 팔기** — 안 판다. 페이퍼(실손 0) + 자동 손절 −8% 가 상한(09-03 에 001210·950220 실증). 팔아도 룰이 참인 동안 내일 다시 산다. 뿌리는 데이터다.
