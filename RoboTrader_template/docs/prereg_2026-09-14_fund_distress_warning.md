## §1. 부실 플래그 정의 — 동결 후보

### 1-1. PIT 규약 (F1 §1-1 을 한 글자도 바꾸지 않는다)

```
D            = 의사결정일(스크리너 scan_date)
연도 선택     = rcept_dt(code, y) <= D-1 인 사업연도 중 «가장 최근» y 를 «하나» 고른다   <- 선택은 여기서 끝
판정          = 그 y 하나에 대해서만. 실패해도 다른 해를 찾지 않는다.
전년 필요 시   = rcept_dt(code, y-1) <= D-1 도 «따로» 요구한다.
원장          = dart_financials_asfiled, status='000' 인 행만
결측          = rcept_dt NULL 또는 status='013' 또는 해당 컬럼 NULL  -> «모름» 계급(§1-3)
```

### 1-2. 주 플래그 `D` — **핵심 합집합 1개** (동결 후보)

```
D(code, Dday) = TRUE  <=>  아래 중 «하나라도» 참
   (a) operating_income(y) < 0                                  ... 영업적자
   (b) operating_income(y) < 0 AND operating_income(y-1) < 0     ... 적자 2년 연속  [ (a) 의 부분집합 ]
   (c) total_equity(y) <= 0                                      ... 완전자본잠식
       OR (issued_capital(y) > 0 AND total_equity(y) < 0.5 * issued_capital(y))  ... 부분잠식 50%+
   (d) total_equity(y) > 0 AND total_liabilities(y)/total_equity(y) > 4          ... 부채비율 400%+
```

🔴 **왜 «합집합 하나»인가**: 등록부 가족 FWER 이 이미 **30.2%**(7검정)다. 플래그 4개 × 전략 3개 = **12 주검정**이면 보정 없이 46.0%가 된다. ⇒ **주 검정은 «합집합 D» 하나**로 두고 **성분별 분해는 「인쇄만」**(REGISTRY 규칙 2 — 판정 언어 금지).

🔴 **이자보상배율(F4)을 «뺐다».** 실측(INV §3-3): `D_icov < 1` 이 영업적자와 **96~100% 겹친다**(ma20 70/70 · daytrading 98/102 · minervini 2/2). 그리고 실제 분모가 `interest_expense`(FY2025 **3.4%** 밖에 없다)가 아니라 `finance_costs`(**금융원가**, 96.9%)라 ***이름이 지표를 잘못 부른다***.
⇒ **인쇄만**: 「흑자인데 금융원가 커버리지 <1」 부분집합(ma20 60 · daytrading 28 · minervini 14 종목-일)을 **별도로 세되 `D` 에 넣지 않는다.** 🔒 사장님이 (a)/(b) 분모를 고르면 후속 사전등록의 표적.

🔴 **`total_equity` 는 총자본(비지배 포함)이다** — 신 원장 대조로 확정(INV §5-1 · 지배주주지분과 최대 -9.3% 차이). 한국거래소 자본잠식률 정의(지배주주 기준)와 **어긋나 있고**, 맞추려면 **2019~2023 연간 백필이 선행**이다. ⇒ **총자본 기준으로 동결하고 정의 이탈을 판정문에 병기한다.**

## §3. 검정 설계 — **결과 변수가 꼬리다**

### 🆕🔴🔴 3-0. 주 설계 = **종목-일 연관 패널** (결정 09-15 2)

> **검정 문장(동결)**: ***「부실 플래그 `D` 가 붙은 «종목-일» 은 안 붙은 종목-일보다 꼬리(손절 갭 관통 · 일간 −8% 급락)를 더 자주 겪는가.」***
>
> 🔑 이것은 **「슬롯 기계가 좋아지나」가 아니라 「플래그에 정보가 있나」**다. ***두 질문은 다른 질문이고, 두 번째가 첫 번째의 «전제»다.***

#### 3-0-a. 왜 바꿨나 — 한 줄

기존 §3(슬롯 반사실)은 `B`(현행 top-K) 와 `BD`(`(D,UNK,rank)` top-K) 를 비교한다. 그런데 두 팔은 **같은 날 같은 후보 풀에서 top-K 를 고르므로 슬롯의 대부분을 공유**한다:

```
delta = rate(B) − rate(BD) = r × ( p_out − p_in )
   r     = 슬롯 교체율            ← 선형 희석 계수
   p_out = BD 가 «밀어낸» 플래그 종목의 꼬리 발생률
   p_in  = BD 가 «끌어올린» 비플래그 종목의 꼬리 발생률
```

⇒ ***슬롯 설계가 판정하는 `delta` 는 플래그 효과의 «`r` 배로 희석된» 값이다.*** 그리고 **종목-일 패널은 `r` 로 희석되지 않는다.**

> 🔴 **후보 원장의 한 행은 「그날 살 수 있었던 종목」이 아니다.** 재현 원장은 `screener_snapshots` 와 같은 지점, 즉 **안전필터 «이전»** 을 재현한다. **라이브 실측(2026-08-10) 조회 71건 중 6건(고유 5종목 ≈ 8.5%)이 등록 단계에서 배제**됐다(VI 2 · 관리종목 3 · 거래정지 1). ⇒ ***후보 원장으로 「노출」·「보유」·「매수 가능」을 계산하면 8~9% 를 과대계상한다.***

🟢 **주 설계(§3-0-b)는 후보 원장을 안 쓰므로 해당 없음.** 🔴 **§3-0-c 슬롯 인쇄 arm 에는 그대로 걸린다** — 그 arm 의 노출·`r̂` 숫자에 이 문장을 **병기**한다.

### 3-1. 비교 대상 (동결 예정)

| Arm | 정의 | 역할 |
|---|---|---|

🔴 **`B` 도 같은 귀무 검정을 받는다.** 못 넘으면 ***현행 상위 K 고르기가 「그날 후보에서 무작위 K개」와 구별되지 않는다***는 뜻이고, 등록부 「계열 관측 — 다섯 번」에 여섯 번째가 추가되는 것이며 **그 자체가 가장 중요한 결과**다.

### 3-2-b. 🆕🔴🔴 **20일 실현변동성 대조군 — «필수»** (C-6 · 이 문서에서 가장 값싼 반증 장치)

> **검정 문장(동결)**: *「재무 부실 플래그 `D` 가 **20일 실현변동성 «위에»** 증분을 주는가.」*

**왜 필수인가**: 문헌이 말하는 부실의 성질은 **「낮은 평균」이 아니라 「큰 변동성·꼬리」**다
(Campbell-Hilscher-Szilagyi 2008 · Bali-Cakici-Whitelaw 2011 MAX). 🔑 그런데 ***그 일은 실현변동성이
더 직접적으로, 더 최신 정보로, 공짜로 한다*** — 우리 결과 지표 (i) 가 바로 「꼬리」다.

**정의 (동결 · 결과를 보고 바꾸지 않는다)**

```

   실측 채움률 = 2021 이후 99.83% (CRITIC #14)

flag_cliff(code, t) = TRUE
   ⟺  (1) close_t / close_{t−1} − 1  ≤  −18%                                  ... 절벽 크기
   ∧  (2) open_t / close_{t−1} − 1  ≤  0.80 × (close_t / close_{t−1} − 1)     ... 갭 성분이 당일 총 하락의 80% 이상 (🔒 양변 음수)
   ∧  (3) volume_t ≤ 2.0 × mean(volume_{t−20 .. t−1})                          ... 거래량 무증가

   직전 20봉이 «다» 있을 때만 판정한다. 그 밖은 「모른다」로 따로 세고 건수를 인쇄한다.
   🔒 창(t−20 .. t) 안에서 adj_factor 가 «불변»일 때만 판정한다. 변했으면 「모른다」로 빼고 건수를 인쇄한다
      (= 「직전 20봉이 다 있을 때만」과 «같은» 처리 · 새 문턱이 아니다 · C1).
   🔒 이 정의는 «원시 daily_prices 직접 조회»라 읽기 계층 «밖»이다
      ⇒ volume × COALESCE(adj_factor,1) 을 «곱한다» (이중조정이 아니라 미조정을 메우는 것 · C8).
   가격에는 adj_factor 를 곱하지 않는다(가짜 절벽).
```

**세 문턱의 근거 — 한 문장**: ***기계적 권리락은 「갭이 하락을 지배하고 거래량이 늘지 않는다」, 실제 급락은 「장중에 만들어지고 거래량이 급증한다」*** — 세 조건은 그 둘을 가르기 위한 것이다(−18% 는 1:1 무상증자 −50%·유상증자 권리락 −5~−20% 를 덮되 일반 하한가 −30% 부근 급락과 겹치는 구간을 (2)(3) 이 가른다).

✅🆕 **v0.6 — 조건 (2) 부호 정정 · 문턱 변경 아님 · 결정됨 2026-09-15**(사장님 · ② 세 조건 + 부호 정정 승인 · 문턱 불변) (critic 재확인 **C2 MAJOR**). v0.5 의 `|open/prev−1| ≥ 0.80 × |close/prev−1|` 은 **절댓값**이라 ***«상방» 갭도 통과***시켰다 — 시가 **+15%** 로 갭업했다가 종가 **−18%** 로 밀린 날이 `|0.15| ≥ 0.8 × |0.18| = 0.144` 로 성립한다. 그건 산문 *「당일 하락의 80% 이상이 «갭»에서 나왔다」*와 **정확히 반대**(장중 형성)다. ⇒ 조건 (1) 이 이미 `close/prev−1 ≤ −0.18 < 0` 을 보장하므로 **부호 있는 부등식**으로 고친다. 🔴 ***문턱값 0.80 · −18% · 2.0× 는 한 글자도 바뀌지 않았다*** — 바뀐 것은 **부등식의 방향**이고, 값 조회 0회이므로 「값을 본 뒤 문턱 완화」(§10 금지 17)가 **아니다**. 같은 정정이 `backtest/concept_axes/_defs/flag_cliff.sql` 조건 (2) 줄과 재현기 설계서 §8-10-b 인용식에 **같은 커밋에서** 들어간다.

🆕🔴🔴 **v0.4 — 위 구안은 «항등식»이라 폐기됐다** (리뷰 #2 CRITICAL)

`eps := r̂ × 0.5 × p̂_base` 를 `p̂_base ≥ eps / (0.5 × r̂)` 에 **대입**하면

```
p̂_base  ≥  (r̂ × 0.5 × p̂_base) / (0.5 × r̂)  =  p̂_base        ⇒  «항상 참»
```

⇒ ***게이트가 아무것도 걸러내지 않는다.*** 🔑 ***「식으로 동결하면 자유도가 0」은 맞지만, 그 식을 자기 자신을 검사하는 부등식에 넣으면 검사가 사라진다.***

#### 🆕🔴 v0.4 — `eps` 를 «둘»로 가른다 (리뷰 #2·#3)

```

eps_slot   :=  r̂ × 0.5 × p̂_base              ← §3-0-c 슬롯 인쇄 arm 의 문턱 (희석 계수가 여기에만 붙는다)
```

| 왜 갈라야 하나 | 산술 |
|---|---|

| 🔑 `r̂` 은 **슬롯 희석 계수**다 | `delta_slot = r̂ × (p_out − p_in)` — 희석은 **슬롯 arm 에만** 일어난다. **패널은 `r̂` 로 희석되지 않는다**(§3-0-a) ⇒ 패널 문턱에 `r̂` 이 들어갈 «자리»가 없다 |

🔴 **G7 은 꼬리 「값」이 아니라 「빈도」다** — 수익률 계열이 아니고, PnL 을 보기 전에 산출·커밋한다.

### 3-6. 판정 라벨 (사전 고정 · 지금 짓고 나중에 고르기만 한다)

`delta` = 꼬리 발생률 차이 (**낮을수록 좋다** — 부호에 주의).
- **패널(주 검정 · §3-0-b)**: `delta_panel` = `rate(D=1) − rate(D=0)`(`(i)_panel` 기준 · §3-0-b-ii). 🔴 **부호가 슬롯판과 반대 방향으로 정의된다** — 패널에서는 **플래그군이 더 높으면 (가-D)** 다.
- **슬롯 인쇄 arm(§3-0-c)**: `delta_slot` = `rate(B) − rate(BD)`(v0.3 정의 그대로).

🆕🔴🔴 **v0.4 — `eps = 3%p` 는 «삭제»됐다** (리뷰 #3 CRITICAL). 절대 문턱 대신 **식**을 쓴다:

```
eps_panel  :=  0.5 × p̂_base           ← 🔴 주 검정 문턱. r̂ 이 «없다» (§3-5)
eps_slot   :=  r̂ × 0.5 × p̂_base       ← 슬롯 인쇄 arm 전용 문턱
```

🔒 `p̂_base` 는 **§3-0-f 순서 봉인**대로 판정 창을 열기 «전»에, **✅ 결정됨(β) — 판정 창 첫 해 `2024-03-13~2024-12-31`(196거래일 · 판정 제외)** 에서 산출·서명한다(§3-0-f 1). (α) 패딩 정규화값은 나란히 인쇄만(§12) — **`eps` 산식에는 안 쓴다.**
🔴 ***`eps_panel` 에 `r̂` 을 곱하지 않는다***(§10 금지 21) — 곱하면 `r̂=0.08 · p̂=0.20` 에서 문턱이 **10%p → 0.8%p 로 12배 느슨**해져 **(가-D) 를 제조**한다.

**N1(귀무)**: `#{ R_i 가 arm 보다 좋음 } <= 4` — 100 시드 중 96 이상. 단측 순열 `p = (1 + #{...}) / 101` ⇒ 성립 시 `p <= 0.0495`.
시드 100 은 REGISTRY 공통 제약 `S >= 20m - 1`(m=1 -> 19)을 여유 있게 넘고, 메모리 교훈 ***「귀무가 반보수적이었다(실제 1종오류 17~32%)」*** 때문에 **크기정합 + 당일수익률 층화**를 건다.

| 라벨 (사전 고정) | 🆕 v0.4 — **패널(주 검정)** 조건 | 슬롯 인쇄 arm 조건(판정 언어 금지) |
|---|---|---|
| **(가-D) 부실 경고는 꼬리에서 정보다** | `delta_panel >= eps_panel` **그리고** 블록 부트스트랩 귀무 기각 | `delta_slot >= eps_slot` ∧ N1(`BD`) ∧ G2 |

🆕🔴 **U1 「모름」 계급의 패널 처리** (v0.4 · §1-3 U1 승계) — 패널에서도 **`D=0` / 「모름」 / `D=1` 세 군을 «따로» 집계**하고, **라벨 판정에 쓰는 대비는 `D=1` vs `D=0` 둘뿐**이다. 🔴 **「모름」군을 어느 쪽에도 접지 않는다** — 접는 순간 U2(fail-closed) 또는 U3(fail-open) 가 되고 §1-3 이 그 둘을 이미 기각했다. 「모름」군의 꼬리 발생률·규모·연도별 분포는 **§12 에 인쇄**하되 **판정 언어를 쓰지 않는다**. 🔑 ***「모름」이 `D=1` 쪽 발생률에 가까우면 그것 자체가 정보지만, 이 문서는 그 질문에 답하지 않는다.***

- 🔴 **MDE 를 §3 확정 «직후» 계산해 인쇄한다.** 🆕 **v0.4: 두 MDE 를 «따로» 낸다** — **패널**은 **종목 블록 부트스트랩**(고유 종목 수 병기 · §3-0-b), **슬롯 인쇄 arm** 은 두 arm 이 슬롯의 60~70% 를 공유하므로 **짝대응 표준오차 · `DEFF` 1·2 양쪽**(독립 가정 금지 · §5-1). **`MDE > eps_*` 면 판정문에 「검정력 없음」을 병기**한다.
- **「없다」 선언은** 점추정 `< eps_panel` 그리고 패널 `MDE <= eps_panel` 일 때만(슬롯 arm 은 추가로 G2·G11 통과). **그 밖은 전부 「모른다」.**
- 🔴 **전략별로 라벨이 다를 수 있다.** 「3전략 중 하나에서 (가-D)」를 **「재무 부실 경고는 정보다」로 일반화하지 않는다.**
