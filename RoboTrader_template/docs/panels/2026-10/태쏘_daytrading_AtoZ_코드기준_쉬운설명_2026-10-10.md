## 1. daytrading — 「어제 신고가를 거래량 2배로 뚫은 중소형주를 오늘 산다」

### 1-1 정체
- 유지윤 『하루 만에 수익 내는 데이트레이딩 3대 타법』 **돌파 타법 variant B**(`strategy.py:1-28`).
- 이름은 «데이트레이딩»이지만 코드상 **스윙**이다: 일봉으로 사고 최대 10거래일 보유, 장 마감 일괄청산 없음(`holding_period="swing"` `strategy.py:50` · `base.py:901-914`).
- 주석의 백테스트(2021~2026 · 거래량 상위 50): 706건 · +5.90% · Sharpe 0.17 · 적중 46.7% · «탐색·관찰용»(`config.yaml:6-8`, 재확인 안 함).

### 1-2 후보 뽑기 (장 시작 때 · 전날 일봉 기준)
- **대상**: 직전 거래일 `daily_prices` 전 종목 중 시총 **5,000억 미만**(시총 없으면 제외) · 거래대금 **10억 이상**(`screener.py:16-39`).
- **룰 3개 모두**(`rules.py:263-303` · 창 15 는 `config.yaml:32`):
  1. 종가 ≥ 직전 **15봉**(그날 제외) 고가 최대 → 15일 신고가 돌파
  2. 거래량 ≥ 직전 **20봉 평균 × 2**
  3. 양봉(종가 > 시가)
- **순위** = 거래량 배수 내림차순(`screener.py:51-54`). 스냅샷엔 통과 종목 전부 저장 → 봇은 1~20위를 읽고 안전필터(거래정지·VI·관리종목 등) 통과 순으로 **10개**(`candidate_selector.py:1123,1157` · 10 = `trading_config.json` `strategy.parameters.max_candidates`).
- **언제**: 페이퍼 봇이 09:00 첫 루프에서 `scan_date = 직전 거래일`로 생성(`liquidation_handler.py:604`). 실전 인스턴스는 생성하지 않고 같은 표를 10초 간격·최대 15분 기다려 읽는다 — 못 읽으면 그날 후보 0 + 텔레그램(`constants.py:211-212`).

### 1-3 장중 매수
- 판단 데이터 = **어제까지 확정된 일봉**(오늘 미완성 봉은 버림 · `trading_context.py:185-197`). 그래서 장중에 같은 룰을 다시 확인해도 결과는 스크리너와 같다 → 사실상 **「어제 돌파한 종목을 오늘 산다」**.
- 평가 주기: 3초 루프 3번마다 전략 하나씩 차례(`main.py:433-434`) → 페이퍼(8전략) ≈ 72초에 1번 · 실전(1전략) ≈ 9초에 1번(최소값).

| 매수를 막는 것 | 값 | 위치 |
|---|---|---|
| 하루 매수 | **5건**(매수 체결만 셈 · 10-08~) | `strategy.py:132,152` |
| 동시 보유 | **10종목** | `config.yaml:42` |
| 진입 밴드 | 현재가 ≤ **어제 종가 × 1.03**(하한 없음) | `strategy.py:84` · `trading_decision_engine.py:440` |
| 지수 급락 | 종목이 속한 시장 지수 KOSPI ≤ −2.5% / KOSDAQ ≤ −3.0% 면 차단(`regime_index:auto`) | `constants.py:224-225` |
| 하락장 게이트 | 없음(`regime_gate:none`) | `trading_config.json` |
| 하루 손실 | 전체 실현손실 10% 이상이면 모든 전략 매수 중단 | `trading_context.py:428-436` |
| 중복 | 다른 전략이 보유 중인 종목은 안 산다 | `trading_analyzer.py:130-133` |
| 속도 | 새 진입 60초 간격 → on_tick 1번에 사실상 1건 | `constants.py:422` |

- **금액**: 페이퍼 = 전략 가상자본 1,000만 ÷ 자리 10 = 종목당 **≈100만**(자본 증감에 따라 재산정 · 상한 300만 · `initializer.py:487-508`). 실전 = cap 500만 × 9% = 종목당 **최대 45만**(`fund_manager.py:212,265`).
- **주문**: 페이퍼 = 현재가 즉시 체결(슬리피지 0). 실전 = 현재가 **지정가**, 5분 미체결 시 취소, 부분체결은 체결분만 보유.

### 1-4 매도 (먼저 걸리는 것 하나)

| 사유 | 기준 | 판정 방식 |
|---|---|---|
| 익절 | 체결가 **+10%** | 실시간 현재가 · 약 3초마다(`position_monitor.py:314-323`) |
| 손절 | 체결가 **−10%** | 같음 · 단 09:00~09:04 는 손절을 보지 않음(`:219-224`) |
| 기간 | **10거래일** | 매수일을 포함해 세어 D+10일 장 시작에 매도(`state_restorer.py:399-403`) |
| 추적손절 · 장마감 청산 | 없음 | `trail_ma: null` · swing |

- 실전 매도 = 시장가. 비용 = 수수료 0.015%(양쪽) + 거래세 0.18%(매도). 페이퍼 DB `profit_loss` 는 비용 빼기 전.

### 1-5 실제 예시 (페이퍼 DB · 대표 사례)
- **익절** `393210`: 직전 거래일 종가 4,060원(15일 고가 3,315원 돌파) → 9-28 09:02 **3,905원** 267주 매수(밴드 상한 4,181원 안) → 09:25 **4,405원** 매도 **+12.80%**(+133,500원 · 비용 전). 10%보다 더 받은 건 현재가 확인 사이에 가격이 뛰었기 때문.
- **손절** `419050`: 직전 거래일 종가 1,936원 → 9-28 09:29 **1,945원** 536주 → 9-29 13:09 **1,750원** **−10.03%**(−104,520원).
- **기간 만료** `190510`: 9-22 09:01 「보유기간 10일 초과」로 매도(+61,440원).

### 1-6 코드에서 보인 주의점
1. `max_capital_pct 0.16` 은 **효과 없음** — FundManager 가 전략별 상한 없이 만들어진다(`main.py:130`). 실제 한도는 가상자본 1,000만·종목당 금액.
2. 장 시작 콜백 `on_market_open` 은 **첫 전략(elder) 하나만** 불린다(`main.py:257-265`). daytrading 하루 매수 카운트 리셋은 매일 07:40 재기동에 기대고 있다 → 평소엔 문제없음, 장중 재기동하면 그날 카운트가 0부터 다시 시작.
3. 실전 인스턴스 로그에 「[PAPER] 매수 시그널」이 찍힌다 — 전략 `config.yaml` 의 `paper_trading: true` 를 읽기 때문(`strategy.py:93`). 실제 주문 경로는 `instances/daytrading/trading_config.json`(`false`)을 따르므로 **실주문은 나간다**. 표시만 틀림.
4. 수능일(11-19 · 개장 10:00)에도 손절 유예 창이 09:00~09:04 로 고정 → 그날은 첫 5분 유예가 없다.
5. `trading_config.json` 의 `buy_budget_ratio`·`max_position_ratio`·`max_position_count`·`buy_cooldown_minutes` 등은 읽히지만 쓰는 곳이 없다.

### 1-7 실전 인스턴스 (설정 기준)
- `instances/daytrading/trading_config.json`: `paper_trading:false` · daytrading 만 enabled · `real_total_funds_cap: 5,000,000`.
- 작업 스케줄러 `KisTemplate_RealDaytrading` = **Disabled**.
- 기동 시 미체결 전부 취소 → 계좌·DB 대조, 하나라도 어긋나면 `LiveStartupAbort`(종료 코드 2 + 텔레그램).

### 1-8 연구 중 (라이브 아님) — 테마 순위 층
- `backtest/concept_axes/theme_rank/`: 같은 날 daytrading 후보 중 «같은 테마 동료가 시장 대비 +5%p 이상 2개 이상 튄 정도»(이항 꼬리확률 → 점수 S) 순으로 고르면 지금 순위(거래량 배수)보다 나은지 과거로 비교. 하루 5·자리 10·밴드 +3% 체결을 그대로 재현. 판정 미실행.

- 청산은 룰에 없다. 백테스터 인자로 준다(지정 안 하면 sl 3%·tp 5%·5봉 · `scripts/book_portfolio_multiverse.py:578-580`).

## 3. 한 줄 요약
