## 정해 주실 것 — A (7개)

**A-1. 「있음」 문턱을 두 청산 규칙 모두에 걸까?** (권고: 예)
- 같은 날 −10% 손절선과 +10% 익절선을 둘 다 건드린 봉은 «손절 먼저» 판과 «익절 먼저» 판 두 가지로 계산함.
- 지금은 «평균 −0.4%p 이하» 조건을 손절 먼저 판에만 검사. 예: 손절 판 −1.5%p · 익절 판 −0.3%p 여도 「있음」.
- 권고대로면 두 판 모두 −0.4%p 이하여야 「있음」. 실제로는 p<0.05 면 거의 자동 충족이라 손해 없음(critic).

**A-2. «가짜 급락» 뺀 판도 통과해야 「있음」?** (권고: 예)
- 예: 000500 이 권리락 날 −37.52% 로 보였던 것처럼, 유상증자 공시 종목은 보유 10일 안에 권리락이 떨어질 수 있음 → 공시 종목이 실제보다 나빠 보임(가설 쪽으로 유리하게 왜곡).
- 권고: 보유 창(진입 뒤 10거래일)에 급락 표식(FD1 때 사장님이 동결한 −18% 식 · 수정계수 계단 · ±30% 봉)이 있는 거래를 양쪽에서 똑같이 뺀 판도 계산 → 그 판도 통과해야 「있음」. 더 엄격해지는 쪽.

**A-3. 도구가 실패하거나 공시 후보가 100개 미만이면 아예 열지 않기?** (권고: 예)
- 봉인 때 이미 결론이 정해지는 경우(검정 도구 탈락 · 표본 부족). 열어도 새 정보 없이 «안 본 구간» 만 써버림.
- 권고: 열지 않고 「판정 불가/판별 보류」 를 봉인 근거로 기록.

**A-4. 재봉인 허용 범위** (권고: 1회까지 + 종목별 지문 + 첫 봉인과 차이표)
- 매일 저녁 수집이 옛 수정계수를 다시 써서 «데이터가 바뀌었다» 로 봉인/개봉이 막힐 수 있음. 그때 다시 봉인하는 것을 1회까지만 · 바뀐 종목 목록과 차이표를 남김 → «도구 쇼핑» 차단.

**A-5. 2024-03 이전·이후 거래정지 판정 기준 통일?** (권고: 예)
- 등록부에 이미 «2024-03-13 전후로 가격 자료 모양이 다르다(정지일이 빈칸 vs 거래량 0)» 경고가 있음. 지금 코드는 거래량 0 만 정지로 봄 → 이전 구간에서 정지를 놓치고, 정지가 «상장폐지 누락» 으로 잘못 셀 수 있음.
- 권고: 정지일 = 거래량 0 ∪ «처음과 끝 사이 빈 날», 생존자 누락률에서는 빈 날을 따로(제외·인쇄). 수익을 안 보는 건수 확인을 지금 돌리는 중.

**A-6. 검정 도구 채택 조건에 «한쪽 꼬리» 검사 추가?** (권고: 예)
- 본 검정은 «손해 쪽» 한쪽만 봄. 도구 시험(가짜 표식 400)은 지금 양쪽만 봄 → 손해 쪽으로 너무 쉽게 «있음» 이 나오는 도구를 못 거름.
- 권고: 가짜 표식의 손해 쪽 거부율 ≤ 0.075 일 때만 그 도구 사용.

**A-7. build→봉인→개봉을 한 자리에서(주말 또는 평일 저녁 수집 전)** (권고: 예) — A-4 와 같은 이유.

## 정해 주실 것 — B (4개)

**B-1. 봇 스냅샷과 안 맞는 날도 표본에 넣기?** (권고: 넣음 + 멈춤 규칙)
- 표본 = 기록기가 07:52 에 직접 계산한 후보라 봇 스냅샷과 1~4종목 다를 수 있음(10-07 · 10-06 · 10-02 대조: 봇 후보 전부 포함 · 추가 1~4).
- 권고: 넣되, 불일치가 5일 연속이거나 20일 중 20% 넘으면 멈추고 원인 분류.

**B-2. 라이브 API 파일 2개가 바뀌면?** (권고: 경고만)
- 지금은 라이브 파일 7개 중 하나라도 바뀌면 기록이 멈춤. 08-01 이후 7개 합계 16커밋 → 6개월 봉인 동안 10~20번 멈출 수 있음.
- 기록기는 API 파일 2개를 가져다 쓰지 않음(기록 값 안 바뀜) → 그 2개는 «경고만», 스크리너 5개는 지금처럼 멈춤.

**B-3. 신용 시차가 안 정해지면?** (권고: 시험 10일 한 번 더 → 그래도 안 되면 신용 빼고 3개로)

**B-4. 보유 중 권리락 낀 거래는?** (권고: 주 검정에서 뺌 · 뺀 판/안 뺀 판 둘 다 인쇄) — A-2 와 같은 취지.
