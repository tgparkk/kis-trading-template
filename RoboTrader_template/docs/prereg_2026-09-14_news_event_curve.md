### 0-2. 이 문서의 범위 — 네 문장

1. **표본이 `NW1` 과 다르다.** `NW1` 은 **우리 후보-일**(825~1,131건)을 보고, 이 문서는 **시장 전체 사건**을 본다.
   🔑 ***「후보에 안 붙는다」와 「시장에 사건이 없다」는 다른 말이다*** — `NW1` 의 (바-N) 커버리지 판정이 이 문서를 막지 않는다.
2. **시간축이 다르다.** `NW1` 은 달력(D = `scan_date`), 이 문서는 **사건시 τ**(τ=0 = 정보가 처음 «거래 가능해지는» 거래일).
3. **이 문서는 라이브를 한 줄도 안 바꾼다.** 코드 0줄 · SQL 과 문서만. 배선은 별도 설계·별도 PR.
4. 🔴 **이 문서가 답할 수 «없는» 것**: 「그 플래그로 우리 순위를 바꾸면 성적이 좋아지나」.
   그건 shadow 의 `reorder_topK` 로만 관측된다. ***판정문에 이 문장을 그대로 옮긴다.***

#### 🆕 0-2-b. 🔴 「후보 ≠ 매수가능」 (v0.4 삽입 · 리뷰 #7 · 재현기 설계서 §3-0 문안 그대로)

> 🔴 **후보 원장의 한 행은 「그날 살 수 있었던 종목」이 아니다.** 이 원장은 `screener_snapshots` 와 같은 지점, 즉 **안전필터 «이전»** 을 재현한다(`runners/screener_snapshot_collector.py::run_once` 가 `adapter.scan()` 결과를 그대로 저장하고, 거래정지·VI·관리종목·정리매매 배제는 그 뒤 09:00 등록 단계 `core/candidate_selector.py` 에서 일어난다). **라이브 실측(2026-08-10) 조회 71건 중 6건(고유 5종목 ≈ 8.5%)이 등록 단계에서 배제**됐다(VI 2 · 관리종목 3 · 거래정지 1). ⇒ ***후보 원장으로 「노출」·「보유」·「매수 가능」을 계산하면 8~9% 를 과대계상한다.*** 노출을 재려면 `virtual_trading_records` 를 써야 한다.

🟢 **이 문서의 주 검정(시장 전체 사건 표본)은 후보 원장을 안 쓰므로 해당 없음**이다.

## §2. 창·조각 — 결과를 보기 «전»에 고정

### 2-1. 통계량

`AR_iτ` = 초과수익 · `CAR(a,b) = Σ_{τ=a..b} AR_iτ`. **세 조각만 쓴다. 창을 스윕하지 않는다.**

| 조각 | 창 | 뜻 |
|---|---|---|
| **J (점프)** | `CAR(0, +1)` | 즉시 반영분 |
| **Dr (드리프트)** | `CAR(+2, +20)` | 「한 달 뒤까지 가나」 ← **사장님 질문의 핵심** |
| **La (지속)** | `CAR(+21, +60)` | 「더 오래 가나」 |
| (보조 · 인쇄) | `CAR(−10, −1)` | 사전 누출 |
| (보조 · 인쇄) | `CAR(+2, +5)` | **우리 보유창(중앙값 2일)과 겹치는 구간** |

**`ε_CAR = 1.0%p`** 고정 — 왕복 비용 0.21%p 의 **4.8배**. 🔴 결과를 보고 바꾸지 않는다(§8 금지 1).

## §3. 벤치마크·대조군 — 3단으로 «미리» 정한다

1. **시장조정**(주): `AR = r_i − r_mkt` · `r_mkt` = 그 종목 소속시장의 **의사티커**(`daily_prices` 의 `KOSPI`/`KOSDAQ`).
   Brown-Warner(1985)가 일별 자료에서 시장조정과 시장모형의 차이가 작음을 보였다.
2. **특성매칭 대조군**(주 검정의 대조): 사건 종목마다 `[τ0−60, τ0+60]` 에 **어떤 dtype 사건도 없는** 종목 중
   **시총 10분위 × 직전 20일 수익률 10분위**가 같은 **5종목**. `AR = r_i − mean(r_control)`.
   Barber-Lyon(1997) · Lyon-Barber-Tsai(1999): 장기창에서 지수 대비는 편향(신규상장·리밸런싱)이 있다.
   🔑 ***이 대조군이 「그냥 소형주가 그 달에 나빴다」를 걷어낸다*** — 우리 유니버스는 시총 3천억~5천억 이하가 주력이다.
3. **달력시간 포트폴리오**(`La` 판정의 **주** 방법): 매 거래일, 직전 60일 안에 사건이 있는 종목을 동일가중으로 담은
   포트폴리오의 초과수익 시계열 → 평균/t. Jaffe(1974) · Mandelker(1974) · Fama(1998).
   **군집을 구조적으로 흡수**하므로 장기 구간은 이걸 주로 쓴다.

🔴 **대조군 구성은 결과를 보기 «전»에 코드로 고정하고, 매칭 성공률을 인쇄**한다(매칭 실패 사건은 제외 + 건수 인쇄).

## §5. 🔴🔴 「곡선 모양 → 창 길이」 대응표 — **결과를 보기 «전»에 서명한다** (C-2)

> ***이 절이 이 문서의 존재 이유다.*** 곡선을 본 «뒤» 창을 고르면 그건 **결과를 보고 정의를 고르는 절차**다.
> 대신 **모양 → 창 사상(mapping)을 미리 서명**하면 자유도가 묶인다.
> 🆕🔴 **v0.4 정정 (리뷰 #18) — 실효 자유도는 «2비트»가 아니라 «3비트»다.** §5-2 의 `WINDOW()` 가 **4지 택1 = 2비트**이고, 거기에 **§5-3 부호 단서**(`sign(Dr) == −sign(J)` 이면 「배선은 새 사전등록으로」)가 **결과에 따라 갈리는 «한 비트»를 더 얹는다** ⇒ **4 × 2 = 8지 = 3비트.**
> 🔑 ***「길이를 정하는 사상」과 「형태를 정하는 단서」는 둘 다 결과를 보고 갈리는 분기이고, 둘 다 세야 한다.***
> 그 3비트는 **`NW2` 주검정이 이미 대가를 치른다**(CRITIC §3-1) — 🔴 **다만 「2비트라 싸다」는 문장은 v0.4 에서 철회한다.**

### 5-1. 「유의」의 정의 (하나만 쓴다)

```
유의(X)  :=  §4 사건일 블록 부트스트랩 1,000회에서 얻은 CAR(X) 의 95% 신뢰구간이 0 을 «배제»한다
             ∧  |CAR(X) 점추정| ≥ ε_CAR (= 1.0%p)
```
🔴 **둘 다 요구한다.** CI 만 쓰면 표본이 큰 조각(E1 2,841)에서 **경제적으로 무의미한 0.2%p 가 「유의」가 된다.**
🔴 **이 정의를 조각마다 바꾸지 않는다**(J·Dr·La 동일).

### 5-2. 사상 `WINDOW(J, Dr, La)` — 우선순위가 있는 함수 (동결)

```python
# 🔒 NW2 를 돌리기 «전»에 서명한다. 희석군(주검정 ①) 곡선에 적용한다.
def WINDOW(J, Dr, La):
    if 유의(La):                                   # 1순위 — 가장 긴 수명
        return "[D-60, D-1] 상태 창"
    if 유의(Dr) and not 유의(La):                   # 2순위
        return "[D-20, D-1] 상태 창"               # 🔴 Dr 창 길이와 «같게». D-60 이 아니다
    if (not 유의(Dr)) and (not 유의(La)) and 유의(J):  # 3순위
        return "[D-3, D-1] 사건 창"                # 실측 커버리지 1.0~2.4% ⇒ 자동으로 (바-N) ⇒ 순위층 종료
    return "정보 없음 — 희석 순위 층을 «쓰지 않는다»"   # 4순위 · 재질의 없음
```

| 곡선 모양 | 조건 | **NW1 후속의 희석 창** | 귀결 |
|---|---|---|---|
| **La 가 살아 있다** | 유의(La) | **`[D-60, D-1]`** | D-60 이 «처음으로» 근거를 얻는다 |
| **드리프트(과소반응)** | 유의(Dr) ∧ ¬유의(La) | **`[D-20, D-1]`** | PEAD 형. 🔴 **D-60 이 아니다** |
| **점프 후 평평** | ¬유의(Dr) ∧ ¬유의(La) ∧ 유의(J) | **`[D-3, D-1]`** | 커버리지 1.0~2.4% ⇒ **(바-N) 자동** ⇒ **희석 순위 층 종료** |

```sql
-- 6) ⛔동결 후: 특성매칭 대조군(시총 10분위 × 직전 20일 수익률 10분위 · 5종목)
-- 7) ⛔동결 후: 달력시간 포트폴리오(La 의 주 방법)
```

⚠️ **`adj_factor` 를 가격에 곱하지 않는다**(CLAUDE.md · 가짜 절벽). 거래량은 이 설계에서 쓰지 않는다.
⚠️ **읽기는 resolver 경유** — DB명 하드코딩 금지(`resolve_daily_source_db()`).
