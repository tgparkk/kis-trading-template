## 3. 통계량 🔒

- 로트별 **`d = ret_pct(변형) − ret_pct(원)`**(%p). 부호 + = 변형이 낫다.
- **비용**: 원장·진단 규약(로트당 `notional × 0.25%` 고정). 변형은 로트당 매수 1·매도 1 을 바꾸지 않으므로 비용이 같다 ⇒ **d(net) = d(gross)**. 실제 매도세는 청산 금액 비례라 차가 남지만 ≈ 0.2% × |d|(d = 2%p 이면 0.004%p) — 무시(§11).
- **판정 통계량 d̄** = 전략×변형×창 셀의 **에피소드 첫 행** 평균(§4 p 와 같은 표본).
- 병기(인쇄만): 로트 전체 평균 · 에피소드 평균 · 원 단위 합 `Σ qty×(exit_price_var − exit_price_orig)`(정수) · d = 0 로트 비율 · 변형/원 `sl_tp_same_bar`·갭 플래그 건수 · 🔒 **셀마다 원→변형 `exit_reason` 전이표**(sl·tp·trail_ma·max_hold·데이터 청산) · 🔒 **Δhold_days = hold(변형) − hold(원)** 평균·p10/p50/p90.

## 4. p — K2 의 P2 부품(= K4 의 SE 구조) 🔒 · 이름표 해석 = §12-0 🔒 사장님 확인

- **K2 는 1표본 평균에 쓸 수 없다**(P3 가 추정 대상을 지운다). 이 문서의 p = **K2 의 P2 부품 = K4 의 SE 구조**(교정 RESULTS §2·§5-1 에서 K4 는 G-날짜 **E 0.41 · C 0.48 불합격**)이며, **날짜 강건성은 §6 자기 표본 게이트로만 보증한다.**

| 부품 | 적용 | 사유 |
|---|---|---|
| P2 에피소드 첫 행 | **쓴다** — 에피소드 = 셀 표본(①~④ 뒤) 안 같은 전략·종목의 연속 거래일 scan_date 묶음(교정 해석 기록 2 식 · 창마다 재계산) · 대표 = 첫 행 | 연속 후보일 로트는 경로가 겹쳐 d 가 거의 같다 |
| CR1 종목 클러스터 | **쓴다** — 절편만(K=1): `SE² = G/(G−1) · Σ_g(Σ_{i∈g}(d_i − d̄))² / N²` | 같은 종목의 여러 에피소드 |
| P3 날짜 안 분위 | **쓰지 않는다** | d 는 분위가 없는 1표본 평균 · 날짜 안 중심화는 전체 평균을 지운다 |

- `z = d̄/SE` · **p = 2·min(p_up, p_down) = 2Φ(−|z|)**(정규 근사에서 같음) · 🔒 창 E 가족 = 4 변형 × 3전략 = **m 12 고정** · **Holm · α 0.05** — §6 게이트로 탈락한 전략의 셀도 **p = 1 로 가족에 남긴다**(m 을 줄이지 않음).
- **MDE = (2.87 + 0.84) × SE = 3.71 × SE**(Holm m=12 1단계 양측 `Φ⁻¹(1−0.05/24)` = 2.865 + 검정력 80%) — 셀마다 인쇄.
- 병기(인쇄만 · 판정 0): 2원 클러스터(종목 × §6 20거래일 블록 · CGM 식 `V_종목 + V_블록 − V_종목×블록`) SE 와 그 p. 대체 도구로 쓰는 경우는 §6 · §12-1 뿐.

## 5. 창 역할 · 문턱 · 판정 라벨 🔒

- **E = 1차 판정**(Holm m=12) → **C = 확인**: E 에서 방향 후보가 된 셀만, E 방향의 한쪽 p(`p_up` 또는 `p_down`)에 Holm · α 0.05. 🔒 **m_C = E 통과 셀 수** — C 에서 §6 게이트로 탈락한 셀도 **p = 1 로 포함**. 창 배정 = scan_date.
- 선택 사유: 변형이 §2 에 고정이라 E 에서 «고르는» 자유도는 없지만, 한 시기 국면(한 번의 급락·급등 구간)이 만든 차를 거르려면 다른 시기 재현이 필요하다 · E 먼저 = 교정 창 + 시간 순 전향 확인. 대가 = 검정력(§11 · §12-2).
- **θ = 0.25%p**(비용 1회분 · 모문서 §3·§5 와 같은 잣대 · B1 로트 ≈100만원 ⇒ 로트당 ≈2,500원).

| 라벨 (전략×변형 셀) | 조건 |
|---|---|
| **변형이 낫다** | E: p Holm(12) 통과 ∧ d̄_E ≥ +θ ⇒ C: `p_up` Holm(m_C) 통과 ∧ d̄_C ≥ +θ |
| **원이 낫다** | 대칭(d̄ ≤ −θ · C 는 `p_down`) |
| **차이 없음** | E·C **각각** `|d̄_창| < θ` ∧ `MDE_창 = 3.71 × max(SE_CR1, SE_2원)_창 ≤ θ`(유의해도 \|d̄\| < θ 면 이 칸) |
| **판별 보류** | 그 밖 전부 — 하위 표기: (도구) §6 게이트 · (표본) ④ > 1% · (확인 실패) E 통과·C 실패 · (검정력) MDE > θ |

- 적용 순서: (도구)·(표본) 보류 → 방향 라벨 → 차이 없음 → 나머지 보류. 꼬리표(§7)는 방향 라벨 뒤에 붙을 뿐 라벨을 바꾸지 않는다.

## 6. 자기 표본 가짜 시험 🔒 (교정 §10 권고 반영 · 판정 «전»)

가짜 `d* = s × (d − d̄_셀)` — 셀 표본(에피소드 첫 행)에서 평균을 뺀 d 에 무작위 부호. 중심화 사유: 부호 뒤집기 귀무는 평균 0 이 전제다 · 안 빼면 진짜 효과가 블록 분산을 부풀려 가짜 거부가 는다.

| 종류 | 부호 단위 | 시험하는 것 | 시드 |
|---|---|---|---|
| **정규 근사 점검**(F-종목) | 종목마다 `s_g = ±1` | 종목 단위 부호면 CR1 이 정확 분산이라 동어반복 — 남는 것은 정규 근사·소클러스터 오차뿐 | `default_rng([20261003, 1, w, s, v, j])` |
| **F-블록** | scan_date **20거래일 블록**마다 `s_b`(창 첫 거래일부터 연속) | 날짜(국면) 상관 — 같은 시기 로트가 같은 시장 경로를 탄다(종목 클러스터가 못 잡는 성분) | `default_rng([20261003, 2, w, s, v, j])` |

- j = 1…100 · w = 0 E / 1 C · s = 전략 0 ma20 / 1 minervini / 2 daytrading · v = 변형 1~4(변형마다 독립 부호 ⇒ 400 검정이 «≈100개 정밀도»로 줄지 않게) · 부호 = 정렬 순서(종목코드 오름차순 · 블록 순번)로 `rng.choice([-1, 1], n)`. 시드 접두 20261003 = 교정(20261001)·진단/대조군(20261002)과 겹치지 않음.
- 블록 20거래일 사유: 진단 §3(e) 보유 p90(max_hold 청산 제외) = 7~22거래일을 덮는 가장 짧은 달 단위(≈1개월). 🔒 **블록 수 정정**: 달력 기준 E 16 · C 16 이나 ①·에피소드 적용 뒤 «채워진» 블록은 E 셋 다 16 · **C ma20 13 · minervini 15(최소 블록 1행) · daytrading 15**(작성 중 구조 계수) ⇒ 실행 시 창·전략별 채워진 블록 수·최소 블록 크기를 인쇄.

## 7. 변동성 정합 장치 🔒

- 왜: 진단 verifier §8 — 청산 뒤 10일 `ln(high/low)` 가 익절 로트 쪽이 3전략 모두 +1.0~1.3%p 크다. 짝 비교는 같은 로트의 두 청산이라 «두 집단 교락»은 없다(가격이 방향 없는 마팅게일이면 어느 장벽이든 기대 d ≈ 0). 남는 위험 = 변동성에 비례하는 **일봉 기계 효과**(같은 봉 손절 우선 · 갭 체결 · max_hold 절단) — 좁힘(V1·V3)은 동시 터치가 늘어 손절 우선 규약에 불리, 넓힘(V2·V4)은 유리하다.
- **층 변수 v** = 진입 전 20거래일 평균 `ln(high/low)` — 봉 = `date ≤ scan_date(D)`(D 봉은 D+1 09:00 진입 전 확정 · 진입일 봉 제외 · KOSPI 달력 봉만) · 봉 < 15 ⇒ 「층 결측」(주 분석엔 남김 · 건수 인쇄).
- **경계** = 전략별 창 E 셀 표본(①~④ 뒤 전 로트)의 v 33.3·66.7 백분위 → **C 에도 같은 경계**(C 층 크기 불균등 허용 · 인쇄). C 자료는 층 정의에 안 들어간다.
- 🔒 **주 = 비층화 d̄**(§3~5). 층 가중 평균은 **보조·인쇄만** — C 는 **E 구성 표준화 d̄ = 층별 d̄_C 의 등가중(1/3) 평균**. 🔒 층별 d̄ 의 표본 = **에피소드 첫 행** · 인쇄 = 셀×층 d̄ · P2·CR1 SE · n(Holm 가족 밖 · 라벨 없음).
- 🔒 꼬리표 **「변동성 의존」**: 방향 라벨 셀에서 E 또는 C 의 층별 d̄ 가 3층 중 하나라도 라벨 반대 부호 ⇒ 붙인다. 뜻 = 「층 없이 일반화하지 말 것」이지 「그 층에만 쓰자」가 아니다.
- 🔒 꼬리표 **「동시 터치 의존」**(상한 방식 · 표본 = 에피소드 첫 행): 원·변형 각각에서 `sl_tp_same_bar(손절 우선)` 로트의 ret 을 그 브래킷 `tp × 100` 으로 바꾼 **「익절 우선」 d′** 를 재시뮬 없이 계산(그 봉에서 어느 쪽이든 청산이므로 경로 뒤는 같다) → d̄′·p′ 로 §5 라벨 조건을 다시 적용해 깨지면 붙인다.

## 9. 해석 🔒

- **변형이 낫다** ⇒ shadow 계기 후보(그 브래킷을 라이브 로그로 병행 계산 · 별도 사전등록) — 🔒 **Δhold 병기 필수**(보유일이 늘어난 개선은 자리 점유 비용을 뺀 값이 아니다) · 라이브 룰 변경 근거 아님(~10-16 · 이후도 전향 표본 + 새 사전등록 뒤).
- **원이 낫다** ⇒ 「현행이 그 방향 한 칸보다 나았다」 관측일 뿐 — 역시 근거 아님.
- **차이 없음** ⇒ 이 해상도(일봉 · 한 칸)에서 브래킷 이동은 비용 1회분을 못 넘는다 ⇒ 청산 층 연구는 다른 축(보유기간 · 트레일)으로.
- **판별 보류** ⇒ 「못 재봤다」. 방향 라벨 0 이면 진단의 비대칭은 «돈이 되는 방향»으로 확인되지 않은 것이다(변동성 차이 설명과 정합할 뿐 · 증명 아님).
