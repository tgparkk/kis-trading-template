## 6. 한계·주의 — 쉽게 써도 없어지지 않는 것

- **한 국면이다.** 65거래일, KOSPI −24% 폭락 → 반등. 「minervini 가 제일 좋다」가 아니라 「이 국면에서 minervini 만 잃지 않았다」다. 전략당 매도 47~139건은 검정 표본이 아니다.
- **시장보다 덜 잃은 건 알파가 아니다.** 격리 자본이라 전략이 늘 전액 투입 상태가 아니다(09-04 기준 현금 비중: ma20 0.02% · daytrading 6% · ma5 20% · minervini 38% · rs_leader 42% · envelope 46% · elder 66% · deep_mr 100%). 현금으로 있던 만큼은 어떤 전략이라도 덜 잃는다.
- **백테스트 평판 숫자는 라이브 기대치가 아니다.** 라이브 매수의 97% 가 백테스트가 본 적 없는 종목이다(`PAPER_STRATEGIES.md` §0.7). 이 문서엔 백테스트 숫자를 일부러 하나도 안 넣었다.
- **gross 와 net.** 매매별 `profit_loss` 는 gross(수수료 전), 자본 `equity` 는 수수료 반영. 「실현손익 보고는 net 기준」 규칙에 따라 §0 순위는 equity 로 매겼다.
- **원장이 둘.** 봇 로그 총자금과 `paper_strategy_equity` 합이 0.18% 다르다(알려진 결함, 원인 미규명). 전략별 비교는 후자, 일일 EOD 보고는 전자.
- **N-1 이 정리되기 전엔 rs_leader·envelope·deep_mr 의 성적은 「데이터 결함 포함」 성적이다.** ③ 후 후보 집합이 바뀌면 과거 성적과 이어 붙일 수 없다 — 그때 기준선을 새로 잡는다.

## 부록 A. 재현 SQL (전부 `kis_template`, 읽기 전용)

원본 파일과 실행 출력: `scratchpad/report_20260904_8strategies/`(리포 루트, Temp 아님).

```sql
-- 전략별 자본·누적·8~9월·고점 대비 (표 §0)
SELECT a.strategy, round(a.equity) eq_0904,
  round(100*(a.equity/10000000-1),2) ret_total_pct,
  round(100*(a.equity/b.equity-1),2) ret_aug_sep_pct,
  round(100*(a.equity/m.max_eq-1),2) dd_from_peak_pct
FROM paper_strategy_equity a
JOIN paper_strategy_equity b ON b.strategy=a.strategy AND b.trade_date='2026-07-31'
JOIN (SELECT strategy, max(equity) max_eq FROM paper_strategy_equity GROUP BY 1) m ON m.strategy=a.strategy
WHERE a.trade_date='2026-09-04' ORDER BY ret_total_pct DESC;

-- 전략별 매도 건수·승률·gross (표 §0)
SELECT strategy, count(*) n_sell,
  round(100.0*count(*) FILTER (WHERE profit_loss>0)/count(*),1) win_pct,
  sum(profit_loss) gross_pnl,
  round(100.0*count(*) FILTER (WHERE reason LIKE '%손절%')/count(*),1) sl_pct
FROM virtual_trading_records WHERE is_test=true AND action='SELL' GROUP BY 1 ORDER BY gross_pnl DESC;

-- 월별 gross (표 §1)
SELECT to_char(timestamp,'YYYY-MM') ym, strategy, count(*) n_sell, sum(profit_loss)
FROM virtual_trading_records WHERE is_test=true AND action='SELL' GROUP BY 1,2 ORDER BY 1,2;

-- 청산 사유 분류 (§2 각 전략)
SELECT strategy,
  CASE WHEN reason LIKE '%손절%' THEN 'stop_loss' WHEN reason LIKE '%익절%' THEN 'take_profit'
       WHEN reason LIKE '%트레일%' OR reason ILIKE '%trailing%' THEN 'trail'
       WHEN reason LIKE '%보유기간%' THEN 'max_hold' ELSE 'other' END cat,
  count(*), sum(profit_loss)
FROM virtual_trading_records WHERE is_test=true AND action='SELL' GROUP BY 1,2 ORDER BY 1,2;

-- 최근 3건 (§2 실물 예시)
SELECT * FROM (SELECT strategy, stock_code, timestamp::date d, quantity, price, profit_loss, profit_rate, left(reason,40) r,
  row_number() OVER (PARTITION BY strategy ORDER BY timestamp DESC, id DESC) rn   -- id DESC = 같은 초 동률 타이브레이커
  FROM virtual_trading_records WHERE is_test=true AND action='SELL') t WHERE rn<=3 ORDER BY strategy, rn;

-- 0초 왕복(매수→매도 5초 이내) 월별 (§2-5·2-6)
SELECT to_char(s.timestamp,'YYYY-MM') ym, s.strategy, count(*)
FROM virtual_trading_records s JOIN virtual_trading_records b ON b.id=s.buy_record_id
WHERE s.is_test=true AND s.action='SELL' AND s.timestamp-b.timestamp < interval '5 seconds' GROUP BY 1,2 ORDER BY 2,1;

-- 지수 (표 §0)
SELECT stock_code, date, close FROM daily_prices
WHERE stock_code IN ('KOSPI','KOSDAQ') AND date IN ('2026-06-01','2026-07-31','2026-09-04') ORDER BY 1,2;
```
