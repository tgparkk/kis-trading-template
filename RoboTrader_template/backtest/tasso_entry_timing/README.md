### 🔴 「상승폭 → 깊이 대응관계에 정보가 있다」는 **성립하지 않는다** (독립검증에서 철회)

초판 결론은 *"정보는 있으나 손실 축소일 뿐"* 이었다. 사전등록 §4 가 요구한 **s-vs-C2 산출을 `run6.py` 가 빠뜨렸고**(C2 게이트 A 통과 p=0.859 ⇒ 보고 의무), 그 값이 결론을 반증한다.

| 대조군 | 무엇을 파괴하나 | 의도 깊이 일치도 | Δ | pooled t |
|---|---|---|---|---|
| C1 라벨 셔플 | **상승폭→깊이 대응관계** | 셀 평균만 (±0.10%p) | +0.460%p | 24.3 |
| **C2 모양 무작위** | 폭·비중 배치 (**대응관계 보존**) | **행 단위 2.2e-16** | **+0.610%p** | **39.9** |

대응관계를 그대로 둔 C2 를 **더 크게** 이겼다. 대응관계가 원천이라면 Δ(s vs C2) ≈ 0 이어야 한다.
⇒ **Δ 의 정체는 사다리 기하가 만든 「더 깊은 실현 진입가」다.** 실현 깊이 차는 **18/18 셀 전부 전략에 유리한 한쪽 부호**(vs C1 +0.65~+2.51%p, vs C2 +0.45~+2.03%p), 청산가는 양팔 사실상 동일(비 0.99997), Δ/실현깊이차 ≈ 0.51(4차)·0.52(C1)·0.39(C2).

## 이 코드를 다시 쓸 때의 규칙

1. **귀무 실측을 먼저 돌려라** — 대조군 vs 같은 설계 재추첨. 값이 싸고 판별력이 크다(4차 결함을 30초에 잡았을 것).
2. **게이트를 코드 순서로 못 박아라** — `run6.py` 는 게이트 실패 시 주 판정 p 를 **계산하지 않고 종료**한다. 이 순서가 없으면 "결과를 보고 고쳤다"를 스스로도 반증할 수 없다.
3. **미체결을 버리지 말고 현금 0% 로 기록하라** — 버리면 조건화가 편향을 만든다. 5차 → 6차에서 편향이 사라지면서 MDE 도 개선됐다(동일 기준 0.43%p → 0.27%p = **1.6배**. 초판의 "10배"는 서로 다른 통계량을 비교한 오류였다).
4. **「무작위라 공평하다」는 착각** — 무작위화가 어느 축을 건드리는지 세어라. 비중 순열은 평균 매수 깊이를 2.19%p 얕게 만든다(`control5.random_shape_levels` 의 `match_depth` 가 그 교정이다).
5. **「A 를 파괴한 대조군을 이겼다」로 A 의 정보성을 주장하려면, A 를 보존한 대조군은 못 이겨야 한다.** 6차는 그 대조군(C2)을 갖고 있었는데 계산하지 않았다.
6. **게이트는 1차 모멘트만 잡으면 안 된다.** 행 단위 의도깊이 격차의 sd 는 9.2%p 이고 Δ 의 반응은 볼록하다(양의 쪽 기울기가 음의 쪽의 7.5배) ⇒ Jensen 에 의해 **평균 0 인 격차가 구조적으로 양의 Δ 를 만든다.** `|E[gap]|` 이 아니라 `E[|gap|]` 이나 층별 격차를 묶어라.
7. **MDE·SE 는 추론에 쓰는 것과 같은 단위(종목 블록)로 계산하라.** iid SE 를 쓰면 3.6배 낙관적이다.
8. **잡음 많은 선택자(max-t)에 2차 판정 조건을 매달지 마라.** 절대검정이 max-t 셀에만 걸려 있어, 8.2% 확률로 이기는 다른 셀이 뽑혔다면 p_abs=0.017 로 PASS 가 됐다(자본가중이 이 경로를 닫는다).
