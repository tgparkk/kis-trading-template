## 실행 도중 실패 규칙 (사장님이 고름 · 코드는 둘 다 지원)
- **기본 = 재시도 없음**: 표식이 남은 뒤 죽어도 다시 돌리지 않는다(그 시도가 «1회»).
- **`--retry-after-failed-run --retry-reason "<사유>"`**: 직전 시도에 결과 경로가 없고 · `results/` 에 `summary_*.md` 가 없고 · 앞선 재시도가 없을 때만 **1회** 허용. 표식에 새 시도로 `retry: true` · 사유를 덧붙인다.
