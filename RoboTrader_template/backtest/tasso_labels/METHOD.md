## 1. 파이프라인 — 4단계

저자의 매매는 **후보 선정 → 앵커 지정 → 분할매수 → 분할매도**의 4단계다.
**7차가 검정한 것은 3단계 하나뿐이고, 나머지 3단계는 양팔 동일 상수로 묶여 있었다.**

### ① 후보 선정 — 재료 + 시총/거래대금 (`daily_prices` 에 대부분 있다)

- **재료(뉴스·촉매)가 1차 필터.** 전수 집계상 스윙 90종목 중 **88건(97.8%)** 에 선정 근거가 산문으로 적혀 있다.
  ⚠️ 단 `2024단타` 체제는 4/42(9.5%)뿐 — **재료 기반은 스윙 한정**이다.
- 🔑 **재료의 "지속력"을 본다.** *"뉴스의 성격이 **완료형**"* (선정됐으니 끝 / 승인받았으니 끝)이면 거른다.
  후속 보도가 이어질 재료만 취한다.
- 🔑 **"종목의 끼"** — 과거에 어떤 키워드로 올랐는지를 매일 기록해 두고 같은 키워드가 재등장하면 공략.
  키움 HTS `통합메모관리자`에 **2,307종목**을 2023년 2월부터 기록.
- **수급 필터(정량)**:
  - **시가총액 · 거래대금 · 거래대금÷시총 비율** 세 가지. 다날 예시 **0.2368배**(거래대금 830억/시총 3,500억)
  - 바닥권에서 **수천억~1조 원** 거래대금을 터뜨리며 1·2차 시세를 낸 종목의 **첫 눌림목**
  - **시총 5조 이상 대형주는 부적합**(탄력 부족)
- **대장주 우선**: 2등주는 대장주가 5% 빠질 때 10% 빠지고, 폭락장에서 통계 범위를 이탈할 확률이 높다.

### ② 앵커 지정 — **사람이 두 점을 클릭한다** (자동 아님)

> *"차트 위에서 **마우스로 고점과 저점만 딱 두 번 클릭**하면, 통계에 기반한 매수 구간과 적정 비중이
> 선으로 자동으로 그려지게 만드는 것"* · *"고점이 경신될 때마다 최고점만 마우스로 살짝 이동시켜주면"*

- 입력은 **상승 시작점(저점)** 과 **최고점** 두 개. 프로그램은 그 사이 **상승폭**만 계산한다.
- 🔑 **7차 앵커 메모 §5의 결론("고점 자동탐지가 없고 사람이 입력한다")이 저자 본인의 서술로 확정됐다.**
- 실제로 *"삼전닉스의 상승 시작점을 **2024년 말로 잡고**"* 처럼 구간을 사람이 정한다.

### ③ 분할매수 — 상승폭 → 하락폭 분포 → 밴드 → 차수별 비중

```
상승폭 X%  ──(13,503건 통계)──▶  비슷하게 오른 과거 사례의 하락폭 분포
                                      │
                                      ├─ 사분위수(Q1~Q3) 모드  또는  HDR(고밀도) 모드
                                      ▼
                              하락폭 밴드 [d_lo, d_hi]
                                      ▼
              매수 구간 = [ H(1−d_hi) , H(1−d_lo) ] 를 5등분 → 차수별 중심가
                                      ▼
                        프리셋이 차수별 **비중**을 정한다 (밴드는 안 바뀜)
```

- 🔑 **"평균에 사면 안 된다"** — 상승폭 45~48% 사례 **481건 중 평균값 근처에서 반등한 것은 53건(11%)**.
  *"평균은 점 하나인데, 현실은 퍼짐"*. 그래서 점이 아니라 **구간 전체에 나눠 산다.**
- **밴드는 상승폭에 따라 달라진다**: 다날 상승폭 29.8% → 매수구간 4,452~4,126원 /
  코스모로보틱스 86.5% → 15,491~13,240원. *"오른 폭이 다르니 빠지는 깊이가 다르다"*.
- **첫 매수 비중 30~40%**, 추가매수는 첫 매수의 **1.5배 또는 2~3배**(2025-04 서술).
  삼각형 비중(**1:2:7** 또는 **2:3:5**)을 언급한 곳도 있다 → **3분할 판본**도 존재.

### ④ 분할매도 — **「저점 대비 반등폭」의 HDR 구간** (7차가 쓴 규칙과 다르다)

> *"상승 X%, 하락 Y%, **반등 Z%** … 3가지 데이터를 직접 수집"* · *"**HDR = 데이터가 몰려있는 상위 %**"*

- 매도 기준은 **고점 대비가 아니라 「저점 대비 반등폭」** 이다.
- 실측 예: 표본 **441건**에서 HDR 60% 구간이 **9.3%~26.8%** → HDR을 **10%** 로 좁히면 **10.8%~12.7%**.
  다른 케이스는 표본 **349건**에 HDR 10% = **10.7%~12.2%**.
- **하락장에서는 HDR을 좁히고 그 초입에서 전량 또는 보유의 70~80% 매도.**
- 변동성 장세 보조 규칙(다우 이론): 직전 **최고가~최저가의 1/2 ~ 1/3** 반등 구간에서 기계적 매도.
  **저점 이탈 시 손절**, **5~10거래일 무반응이면 비중 축소.**
- **손절 = 「살라미」 분할손절**: 손실률 −20% 초과 시
  ① 보유의 1/2·1/3·1/4 중 하나를 **시장가 일괄매도**
  ② 나머지를 **10/15/20 거래일**에 나눠 매일 **종가**에 매도
  ③ 도중 주가가 **본전가 도달 시 잔량 전량 자동매도**

## 3. 우리 7차 검정과의 대조

### ✅ 맞았던 것

| 7차 가정 | 검증 |
|---|---|
| 상승폭 → 하락폭 밴드 → 5분할 매수 | ✅ 구조 자체가 맞다 |
| 비중 **10/13/17/25/35** | ✅ 실재하는 프리셋 **「표준형」**. 계산기 이미지 **9장**에서 재현 |
| 레벨 5개 **등간격** | ✅ 계산기 이미지 **49/49장** 간격 편차 ≤2원 |
| `center=(Q1+Q3)/2` · `width=c·IQR` · `c≈0.8` (앵커 메모 §6) | ✅ **아래 §4 교차검증에서 정확 일치** |
| 앵커는 사람이 입력 (앵커 메모 §5) | ✅ 저자 서술로 확정 ("고점과 저점 두 번 클릭") |

### ❌ 틀렸거나 좁았던 것

| 7차 | 실제 |
|---|---|
| 청산 = **마지막 체결일 + 20거래일 종가** | **「저점 대비 반등폭」의 HDR 구간 분할매도** — 완전히 다른 규칙 |
| 비중 1종(10/13/17/25/35)만 검정 | **최소 4종**(표준형·안정형·공격형·하이브리드). 5차 비중이 35% vs **50%** vs 30% |
| 후보 선정을 양팔 동일 상수로 고정 | 실제로는 **재료 지속력 + 시총/거래대금/회전율**이 1차 필터 |
| 손절 없음(고정 보유) | **−20%에서 살라미 분할손절**이 실재 |
| 5분할 고정 | **3분할 판본**도 존재(1:2:7, 2:3:5) |

🔑 **7차 FAIL 의 해석은 바뀌지 않는다** — 7차 README가 *"매도·후보 선정은 양팔 동일 상수이며 이 검정은
그 두 단계에 대해 아무것도 말하지 않는다"* 고 명시했기 때문이다. **다만 검정 범위가 생각보다 훨씬 좁았다는 것이
이제 정량적으로 확인됐다.**

## 4. 교차검증 — 독립된 두 증거가 맞물린 지점

### ✅ 삼성전자 Q3 = 167,200원 (정확 일치)

앵커 메모 §6이 **삼성 A급 화면에서 역산**한 값: `Q1=0.353`, `Q3=0.560`, `center=0.4565`, `IQR=0.207`.
2026-07-29 글에서 저자가 직접 쓴 값: *"4분위수 중 **Q3 부분인 167,200원**"*.

```
380,000 × (1 − 0.560) = 167,200원      ← 완전 일치
```

약 1년 떨어진 별개 증거 두 개가 맞물린다. **밴드 모델과 앵커(380,000) 가 동시에 확인된다.**

### ✅ 다날 매수구간 4,452 ~ 4,126원

앵커 메모 §4가 A급 화면에서 읽은 레벨 5개: `4,452 / 4,371 / 4,289 / 4,208 / 4,126`.
2026-07-28 글에 *"저점에서 고점까지 상승폭 **29.8%** / 계산된 매수 구간 **4,452원 ~ 4,126원**"*.
**양 끝이 정확히 일치**한다.

### 🟡 형지엘리트 평단 (0.38% 차)

2026-01-15 글: *"비중은 **5:10:15:20:50**으로 설정 … 전부 체결되었을 때 평단은 **1,767원**"*.
계산기 이미지 #3(형지엘리트·안정형) 중심가 `2,033/1,947/1,860/1,774/1,687` 로 가중평균하면 **1,773.65원**.
차이 **6.65원(0.38%)** — 실제 체결가 기준이거나 반올림 차이로 보인다. **근접하나 정확 일치는 아니다.**

## 6. 미해결 / 주의

- 🔴 **앵커는 여전히 사람의 선택이다.** "고점과 저점 두 점"이 어떤 규칙으로 찍히는지는 규칙이 아니라 재량이다.
  다만 **밴드 상·하단을 51건 확보**했으므로 역산 시도는 가능하다 → [`ANCHOR_STRATEGY.md`](ANCHOR_STRATEGY.md).
- 🔴 **밴드가 일봉 기준이 아닐 수 있다.** 매매 캡처가 **60분봉·5분봉**이다. 일봉으로 재현되지 않을 여지가 있다.
- 🔴 **(날짜, 종목) 라벨은 독립이 아니다.** 같은 포지션이 2~3주 재게시된다 ⇒ **블록 단위 = 포지션**.
- ⚠️ **공개 수익률을 성과로 쓰지 말 것.** 「매도 조건화」 표본이고(미청산은 줄 자체가 없음) 표기값도 차수별 ROI다.
- ⚠️ 이 문서는 **저자의 서술**을 정리한 것이다. 서술이 실제 프로그램 동작과 일치하는지는 **미검증**이다.
