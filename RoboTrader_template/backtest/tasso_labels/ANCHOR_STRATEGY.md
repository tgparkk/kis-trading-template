## 1. 식별 문제 — 정확히 무엇이 미지수인가

관측(케이스 `i` 당): 밴드 상단 `B_hi`, 하단 `B_lo`, 종목, 진입창, 프리셋, 계산기 판본.
미지수: 앵커 고점 `H`, 얕은 깊이 `d_lo`, 깊은 깊이 `d_hi`.

```
B_hi = H (1 − d_lo)
B_lo = H (1 − d_hi)
```

**식 2개 · 미지수 3개 ⇒ 케이스마다 1개 부족.** 그리고 비를 취하면

```
B_hi / B_lo = (1 − d_lo) / (1 − d_hi)        ← H 가 소거된다
```

⇒ 관측 2개 중 **하나는 깊이 구조만** 말하고, `H` 는 **추가 제약 없이는 절대 안 나온다.**
추가 제약은 **가격 데이터**나 **모델**에서 와야 한다. 아래 세 경로가 그것이다.

편의상 **상대폭** `s ≡ (B_hi − B_lo)/B_hi = (d_hi − d_lo)/(1 − d_lo)` 를 쓴다. `s` 도 `H` 무관이다.

### 실측된 `s` (49건, `calc_table.csv`)

| | 값 |
|---|---|
| 중앙 | **14.39%** |
| 범위 | 4.68% ~ 36.98% (**8배**) |
| Ver 1.3 (42건) | 중앙 14.70% · 4.68~36.98% |
| Ver 1.4 (7건) | 중앙 13.36% · 7.34~17.80% |

**폭이 고정이 아니다** — 종목·시점마다 8배 변한다. 즉 밴드는 무언가에 반응해 넓어졌다 좁아진다.

## 2. 경로 1 — 외생 모델 역산 (**주 전략으로 못 쓴다. 부분 반증됨**)

7차 앵커 메모 §6 의 2점 로그보간 모델(`c=0.8`):

```
center(x) = 0.113603 + 0.174276·x      width(x) = 0.048325 + 0.059852·x      x = ln(1+rally)
s(x) = 2·width / (1 − center + width) = (0.09665 + 0.11970x) / (0.93472 − 0.11442x)
```

`s` 는 `x` 에 단조증가라 **가역**이다 ⇒ `s → x → rally → d_lo → H = B_hi/(1−d_lo)`. 케이스마다 정확 식별된다.

**그런데 실측이 이 모델을 부분적으로 깬다:**

| 검사 | 결과 |
|---|---|
| 모델 하한 `s(x=0)` | **10.34%** (rally 0 이어도 이보다 좁아질 수 없다) |
| 실측 `s < 10.34%` (rally<0 ⇒ 불가능) | **10 / 49건** |
| 나머지 39건의 함의 rally | 중앙 41.7% · 범위 4.6~365% |
| 보간구간 `[29.77%, 614%]` 밖 **외삽** | **14 / 39건** |

🔴 **그리고 불가능 10건 중 8건이 `s ≈ 9.68~9.77%` 한 점에 뭉쳐 있다.**
세코닉스·모바일어플라이언스·에스앤에스텍·한전산업·대주전자재료·에코플라스틱 — **종목도 프리셋도 제각각**

⇒ **밴드 폭은 단일한 매끄러운 rally 함수가 아니다. 최소 하나의 이산 레짐이 더 있다**

**사전등록에서 별개 층으로 못 박아야 한다.**

🔧 **2026-08-07 정정 — 「최소 하나」가 아니었다. `s` 는 전 구간이 이산이다.** → [§2.1](#sec-2-1)
**`s≈9.7%` 클러스터는 이상치가 아니라 클러스터 15개 중 하나였다.** 한 층만 떼어내는 조치는

## 3. 경로 2 — 전방 예측 (**주 전략**)

역산하지 말고 **예측**한다. 앵커 규칙에서 `H` 가 나오면 자유모수가 없어진다.

```
후보 규격 = (앵커 규칙 R) × (룩백 L) × (깊이 분포 규격 Q) × (폭계수 c)
    H_i  = R(종목 i 의 진입 이전 시세)                 ← 가격 데이터에서 결정
    깊이분포 = Q(H_i, L)                               ← 예: 룩백 내 낙폭의 Q1~Q3
    예측 밴드 = [ H(1 − c·d_hi) , H(1 − c·d_lo) ]
    오차_i = ½(|B̂_hi − B_hi|/B_hi + |B̂_lo − B_lo|/B_lo)
```

**왜 이게 옳은 방향인가**: Ver 1.4 캡션이 모드를 **직접 명시**한다 — **「사분위수(Q1~Q3)」** 와 **「HDR 60」**.
7차 앵커 메모 §6 이 삼성 화면에서 역산한 `center=(Q1+Q3)/2` · `width/IQR = 0.8019` 와 **같은 구조**다.
즉 계산기는 **종목 자신의 낙폭 분위수**를 쓴다. 그러면 `H` 만 정해지면 밴드는 **가격 데이터로 계산된다.**

🔴 **2026-08-07 — 이 전제가 실측과 충돌한다.** [§2.1](#sec-2-1) 이 **종목이 다른데 `s` 가 0.02pp 안에서
같은 쌍을 43개**(같은 날짜 배치 제외) 찾았다. **종목 자신의** 분위수를 쓴다면 종목이 바뀔 때 `s` 도
바뀌어야 한다. 같은 글의 통계 화면(상승폭 구간별 **모집단** 사례표 · 특정 상승폭 창의 **모집단** 히스토그램)도
**모집단 쪽**을 가리킨다. ⇒ **`Q` 후보를 아래처럼 넓힌다. 두 모델을 격자 안에서 겨루게 하고
사후에 고르지 않는다.**

### 후보 격자 (실행 전 고정, 사후 추가 금지)

- **R**: ① 룩백 `N` 봉 최고 `high` ② 급등봉 이후 최고 `high`(7차 `find_segments_local`) ③ 직전 신고가
  ④ **라운드 반올림판**(§4) — 각 규칙의 값을 유효숫자 2~3자리로 올림/반올림
- **L**: 60 / 120 / 250 거래일
- **Q**: **종목 자신의** 낙폭 분위수 `(Q1,Q3)` / `(P20,P80)` / HDR-60
  · 🆕 **모집단 상승폭 버킷 분포** — 종목 무관, `rally` 가 속한 구간의 **전 종목 낙폭 분포**에서
  `(Q1,Q3)`/`(P20,P80)`/HDR-60 (2026-08-07 추가, [§2.1](#sec-2-1))
- **c**: 0.8 고정(A급 증거값). 스윕하지 않는다 — 격자가 이미 크다.

### 채점

- 주 지표: 오차의 **중앙값**(평균은 외삽 꼬리에 끌린다)
- **블록 = 포지션**, 행이 아니다 (§6)
- 층: `Ver 1.3` / `Ver 1.4` / **`s≈9.7% 레짐`** 을 사전 분리해 각각 보고

## 4. 경로 3 — 반올림 지문 (**독립 교차검증**)

앵커 메모 §5 의 핵심 근거는 *사람이 손으로 입력한다* 였고, 그 증거가 **반올림**이었다:

| 종목 | 태쏘 입력 | DB 실제 고점 | 차 |
|---|---|---|---|
| 삼성전자 | **380,000** | 374,500 | +1.47% |
| SK하이닉스 | **≈3,001,700** | 2,987,000 | +0.49% |
| 다날 | 5,100 | 5,100 | 0 |

⇒ `H` 는 **정확한 고가가 아니라 반올림된 값**일 수 있다. 이건 검정 가능한 지문이다:
경로 2 가 낸 `Ĥ` 의 **말자리 분포**가 균등 귀무보다 **0/00 에 유의하게 뭉치는가.**

경로 2 와 **통계적으로 독립**이므로(하나는 밴드 오차, 하나는 자릿수 분포) 교차검증이 성립한다.
그리고 이게 맞으면 **경로 2 의 후보 R 에 「반올림판」을 넣는 근거**가 된다(위 R④).

## 5. 게이트 (결과 보기 전 통과 필수 — 실패 시 주 판정 계산 자체를 skip)

7차에서 가장 효과가 컸던 장치를 그대로 가져온다.

- **게이트 A — 귀무 실측**: 밴드 ↔ 종목 **셔플** 페어링에 같은 절차를 돌린다.
  셔플에서도 비슷한 오차가 나오면 **절차에 판별력이 없다 ⇒ 즉시 중단.**
  🔑 7차 교훈: *「귀무 실측을 본실행 전에 반드시 돌려라 — 4차 결함을 30초에 잡았을 것」*
- **게이트 B — 정답 존재 단언**: 다날 A급(3,930→5,100)은 이 49건에 **없다.**
  ⇒ 내부 **hold-out** 으로 대체한다: 포지션 단위 train/test 분할, **test 밴드는 가격 데이터만으로 예측**.
  🔑 7차 교훈: *「캘리브레이션 채점 전에 정답이 후보 집합에 실제로 존재하는지 먼저 단언하라」*
- **게이트 C — 레짐 사전 분리**: 🔧 **2026-08-07 재작성.**
  ~~`s < 10.34%` 10건(그 중 8건이 `s≈9.7%` 클러스터)을 별도 층으로 선언~~ —
  **전제가 틀렸다.** `s≈9.7%` 는 이상치가 아니라 **클러스터 15개 중 하나**이고 **`s` 는 전 구간이 이산**이다([§2.1](#sec-2-1)).
  ⇒ 층을 **`s` 클러스터 자체로** 잡고 **클러스터를 블록으로** 채점한다(같은 클러스터 안의 건들은 독립 표본이 아니다
  — §6 의 「블록 = 포지션」과 **같은 클래스의 두 번째 의존성**).
  🔴 **블록 정의는 「구간 교집합」이다 — 거리 문턱이 아니다.**
  ~~경계 0.15pp 단일연결~~ 은 **2026-08-08 에 폐기**했다. 그 기준으로는 **초판 표 8행 중 2행이
  서로 다른 두 버킷을 한 블록에 담고 있었고**, 이 게이트가 **사후 재분할을 금지**하므로 그대로 동결하면
  **문서 자신의 규칙에 의해 복구 불가**였다. 블록은 `band_discreteness.py` 의 `clusters()`(구간 교집합)로 뽑는다.
  🔴 **동결 전에 반드시 그 함수를 한 번 돌려 블록 목록을 확정할 것**(자유모수가 없어 재현이 보장된다).
  🔴 **사후에 클러스터를 다시 자르거나 합치는 것을 금지한다.**
- **게이트 D — 격자 고정**: 후보 R·L·Q 를 실행 전에 적고, 사후 추가 금지. 다중검정은 max-t 로 보정.

## 6. 알려진 실패 경로 (미리 적어둔다)

- 🔴 **밴드가 일봉이 아닐 수 있다.** 2026-07 글에 **60분봉 차트**가 함께 실린다.
  분봉 기준으로 계산됐다면 일봉으로는 재현되지 않는다 ⇒ 그 경우 답은 「일봉으로 식별 불가」이고, 그것도 결과다.
- 🔴 **Ver 1.4 는 모델이 바뀌었다**(사분위수/HDR 모드 명시, 비중 전부 마스킹).
  ⇒ **주 검정은 Ver 1.3(42건)** 으로 하고 Ver 1.4(7건)는 별도 보고.
- 🔴 **(날짜, 종목) 은 독립이 아니다.** 밴드 6개가 2~3주 **재게시**되고 3종목은 밴드를 갱신했다.
  ⇒ **블록 단위 = 포지션.** 행으로 세면 표본이 부풀고 SE 가 낙관된다(6차 「iid SE 3.6배 낙관」과 같은 클래스).
- 🔴 **진입일이 ±1주 불확실**하다(주간 회고 글). 룩백 창의 끝점이 그만큼 흔들린다
  ⇒ 각 후보를 **진입일 후보 5영업일에 대해 전부** 평가하고 **최선이 아니라 중앙값**으로 채점한다
  (최선으로 채점하면 자유도가 늘어 오답 규격을 통과시킨다 — 앵커 메모 §4 의 「임의 부분집합」 함정과 동형).
- 🟡 **정말로 규칙이 없을 수 있다.** 사람이 눈대중으로 찍는다면 어떤 R 도 안 맞는다.
  그 결과 역시 **유효한 답**이며, 「앵커는 복원 불가」를 처음으로 **실증**하는 것이 된다.

## 7. 예상

**예상: 부분 성공.** 근거 셋.

1. `s` 중앙값 14.39% 는 외생모델에서 **rally ≈ 30%** 에 대응하고, 이는 다날 실측 29.77% 와 거의 일치한다
   — 모델이 최소한 중앙 대역에서는 옳은 축을 잡고 있다는 뜻이다.

3. 반면 `s≈9.7%` 클러스터(8건)와 외삽 14건은 단일 모델로 설명되지 않는다.

⇒ **일부 층에서는 `H` 가 식별되고 일부는 안 될 것**으로 본다. 그 경계를 긋는 것이 이 작업의 실제 산출물이다.
