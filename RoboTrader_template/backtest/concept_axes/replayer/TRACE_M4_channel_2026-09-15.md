## 3. 자연실험 — 「아직 재기록되지 않은 하루」

오늘(2026-09-15 13:37)은 장중이고 오늘의 15:35 sweep 이 **아직 돌지 않았다**. 따라서
`scan_date = 2026-09-14` 의 D 행은 09-15 09:00:37 스냅샷 «이후» 어떤 쓰기도 받지 않았다.

```

2026-09-14  20      0          0       1.0000      1.000000   ← 사후 재기록 없음
2026-09-11  20     19          0       0.9735      0.993369
2026-09-10  20     20          0       0.9425      0.994480
2026-09-09  20     20          0       0.9579      0.991420
…  (66거래일 전부 n_gt1 = 0)
```

🔑 **20/20 이 `1.00000000`(부동소수 상대오차 0)** — 룰·20봉 창·`volume × COALESCE(adj_factor,1)`
식이 라이브와 비트 단위로 같다는 뜻이다. 즉 **M4 불일치는 룰이 아니라 데이터 변이 하나로 설명된다**.
이 한 줄이 H2(창 어긋남)와 H3(adj 이중/미적용)을 동시에 죽인다.

  `ovtm_vol`(D 하루치)와 맞을 이유가 없다. 실측은 166행이 **단위 주까지 정확히** 일치한다 ⇒ D-1 이전 봉은 이미 수렴해 있다(재기록돼도 값이 안 변한다).
  다만 이건 「역산이 D 한 봉만 잰다」의 **사후 확인**이지 사전 보장은 아니다.
- **남은 구멍**: `m4_pass=t · ovtm_vol>0` 39행 — 시간외가 있었는데 `daily_prices` 가 **끝내 안 받았다**(delta 중앙값 0).
  자가치유가 «항상» 도는 게 아니라는 뜻이라 별개 축이다(§9 P3).

## 6. 수렴/분리

- H1(쓰기 채널)과 H4(값이 커짐)는 **같은 사건의 두 얼굴**이다 — 분리 불가, 하나의 근본원인으로 병합한다:
  **「같은 봉을 두 시점에 두 번 쓰는데, 첫 기록이 시간외 이전이다」**.
- H2·H3·H5 는 서로 다른 근본원인이었고 **각각 독립 증거로 기각**됐다(하나의 증거로 뭉개지 않았다).

## 7. 결론 — 경로 (증거 등급 1차)

```
D 15:30         정규장 마감
D 15:35~15:46   collect_daily sweep → D 행 INSERT (정규장 거래량만)          [F3·F4]
D 15:40~18:00   시간외 종가·단일가 체결 (이 시점 DB 엔 안 들어감)
D+1 09:00:3x    스크리너 스냅샷이 «그 값»을 읽어 score 로 박제              [F1·F2]
D+1 15:35~15:46 같은 sweep 이 최근 7봉을 다시 UPSERT → D 봉이 시간외 포함 값으로 «커진다» [F4·F5·F7]
```

⇒ **부호가 항상 한쪽인 이유는 시간외 거래량이 음수가 될 수 없기 때문이다.** 「데이터가 나중에 바뀐다」가 아니라
**「라이브가 읽은 값은 원래 미완성 봉이었고, 하루 뒤 완성본으로 자가치유된다」**가 정확한 진술이다.
재현기의 결함도 라이브의 결함도 아니다 — **비교되는 두 값의 «빈티지»가 다르다**.

## 8. 재현기는 「라이브 09:00 시점 값」을 재구성할 수 있는가

- **부분적으로만 가능**, 그리고 **M4 의 1e-6 허용오차를 만족시킬 만큼은 불가능**하다.
  - 근사 복원식: `live_volume(D) ≈ daily_prices.volume(D) − overtime_daily.ovtm_vol(D)`.
  - 실측 잔차 중앙값 = D 거래량의 **0.027%**(시간외 «종가» 15:40~16:00 분으로 추정 · 저장 소스 없음)
    ⇒ ma20 score 상대오차 ≈ 1.3e-5 ≫ `M4_REL_TOL = 1e-6`.
  - `overtime_daily` 는 **2026-07-03 부터**(50거래일)만 있다 — 게이트 창 시작 2026-06-05~07-02 는 **원리적으로 복원 불가**
    (30일 롤링이라 소급 수집도 불가 · `collectors/market_flow_collector.py:188`).
  - ma20 1,151행 중 **258행(22.4%)** 은 대응 `overtime_daily` 행 자체가 없다.
- **그래서 M4 의 의미는 이렇게 재정의돼야 한다**(문턱은 건드리지 않는다):
  - 현행 M4 = 「라이브가 **D 15:3x 빈티지**로 계산한 score」 대 「재현기가 **현행(시간외 포함) 빈티지**로 계산한 score」의 비교
    ⇒ **룰 충실도 지표가 아니라 「데이터 빈티지 동일성」 지표**다.
  - 룰 충실도는 §3 자연실험이 이미 `1.00000000`(20/20)로 보여 줬다 — **빈티지를 맞추면 M4 는 정확히 1 이 된다**.
  - ⇒ M4 를 룰 판정으로 쓰려면 **동일 빈티지 대조**가 전제다. 사후 소급으로는 만들 수 없고,
    **앞으로 매일 D 15:50 에 7봉 창을 동결(스냅샷)하는 것**만이 유일한 무손실 경로다.
  - 🔴 **문턱·판정 규칙 변경은 이 문서의 소관이 아니며 제안하지 않는다.**

## 10. 불확실성

- 「첫 기록이 시간외 이전」은 **시각 증거(15:35 INSERT)와 증분 일치(§4)에 의한 간접 확정**이다.
  KIS 응답 자체를 두 시점에 캡처한 직접 증거는 없다(P2).
- 잔차 중앙값 0.027% 를 「시간외 종가」로 부르는 것은 **미확정 귀속**이다 — 저장 소스가 없어 지금은 확증도 반증도 못 한다.
- `delta < ovtm_vol` 인 38행(4.3%)은 미설명이다.
- 2026-06-05~07-02 구간에 이 경로가 성립한다는 것은 **부호 일관성(ratio<1 · gt1=0)의 외삽**이다 — 그 구간엔 시간외 데이터가 없어 직접 증거가 아니다.
- 이 추적은 `book_pullback_ma20` 의 역산(ma20 전용 식)에 근거한다. daytrading 에 대해서는 **부호·크기 모두 미측정**이다(P4).
