## §1. 목적과 배경

### 1-1. 무엇을 묻는가

현행 진입 룰은 **「직전 30봉 안 고저폭 25% 이상」 ∧ 「저가가 MA20 ±2% 터치」 ∧ 「종가 ≥ MA20×0.98」 ∧ 「양봉」** 넷뿐이다. ***「얼마나 깊이」·「며칠에 걸쳐」 눌렸는지는 한 글자도 안 본다.*** 이 문서는 그 둘이 정보인지 묻는다. 🆕 그리고 사장님 결정(2026-09-05)으로 **「같은 업종이 그날 함께 눌렸나」**를 **주 검정으로** 함께 묻는다.

### 1-2. 🔴 이미 판정이 «끝난» 축 — 여기서 다시 열지 않는다

| 축 | 판정 | 출처 |

### 1-3. 판돈 — 왜 이 축인가

8월 ma20 은 **+20.13%**(6,365,446 → 7,647,025 · 매도 28 · 승률 71.4% · 계획서 §0)로 2위였고, 룰 트리거의 평균 창 고저폭은 **85.5%**(문턱 25%의 3.4배 · `ma20_진입룰_점검` §3)다. ⇒ ***25% 문턱이 사실상 안 걸린다.*** 실제로 골라내는 것이 「급등」이 아니라면 **남은 후보를 가르는 것은 「그 뒤 어떻게 눌렸나」**여야 한다. 그것을 아직 **아무도 재지 않았다**(REGISTRY 등록부 #3).

## §2. 개념축 정의 (동결 대상) — 깊이와 기간

### 2-1. 고정하는 것 (전 arm 동일)

`base_filter`(시총 **≤ 3조** · 거래대금 **≥ 10억** · `screener.py:17-19`) · `score` = **현행** `df["volume"].iloc[-20:].mean()`(`screener.py:41`) · `max_candidates = 10` · 청산 **tp +10% / sl −8% / max_hold 50거래일**(`config.yaml`) · 창 · OHLC 보정 · `BookBacktester`.
🔑 **`score` 고정 근거**: 랭킹은 (나)로 판정났고 *「정보가 아니다」*는 **arm 간 차이에 기여하지 않는다**는 뜻이라 오히려 고정하기 좋다(`ma5/PREREG.md` §2 와 같은 논리). 절대 수준은 **「정보 없는 랭킹 위의 값」**이다.

### 2-2. 깊이 `retr` (동결) — **MA20 거리를 쓰지 «않는» 이유를 먼저 적는다**

계획서가 예시로 든 `(MA20 − low)/MA20` 은 이 축에 쓸 수 없다. 룰이 이미 `|low − ma20|/ma20 ≤ touch_tol = 0.02`(`rules_daily.py:94`)를 요구하므로 그 값은 **정의상 [−2%, +2%] 에 갇힌다.** ⇒ 그것은 «눌림의 깊이»가 아니라 **«터치의 정밀도»**다. **값을 보기 전에 이 선택을 못박는다.**

```
seg  = df.iloc[-(30+1):-1]          # rules_daily.py:56 과 «같은» 구간 (직전 30봉, 신호봉 제외)
H    = seg["high"].max()            # 동점이면 «가장 이른» 봉 (numpy argmax 기본)
L    = seg["low"].min()             # 동점이면 «가장 이른» 봉
retr = (H − low_t) / (H − L)        # low_t = 신호봉(당일) 저가
```

🔑 **분모 `H − L` 은 새 모수가 아니다** — `_recent_surge` 가 이미 `(H−L)/L ≥ 0.25` 로 쓰는 «그 값»이다 ⇒ **자유모수 0.** `retr` = 「급등폭의 몇 %를 되돌렸나」.

| Arm | 조건 | 뜻 |
|---|---|---|
| **`Pd1`** 얕음 | `retr < 1/3` | `retr < 0`(신호봉 저가가 창 고가보다 위 = 되돌림 없음) 포함 |
| **`Pd2`** 중간 | `1/3 ≤ retr < 2/3` | |
| **`Pd3`** 깊음 | `retr ≥ 2/3` | `retr > 1`(창 저가마저 깨고 내려옴) 포함 |

🔴 경계 **1/3·2/3 은 「3등분」이라는 산술**에서 나왔고 우리 데이터 분포에서 유도하지 않았다(`ma5/PREREG.md` §2-4 의 「절반」과 같은 형식). 🔴 `retr < 0` 과 `retr > 1` 건수는 §6-2 에 **따로 인쇄**한다.


⚠️ `Pd` 3개와 `Pt` 3개는 **각각 `P0` 의 «분할»**(상호배타·전부 덮음)이나 **`Pd` 와 `Pt` 는 서로 겹친다**(§7-5).

## §3. 🆕 섹터 동조 축 `Ps` — 태쏘 `SEC-M1` 의 «하락 거울상»

🔒 사장님 결정 2026-09-05: 「눌림목 실험에 **「같은 업종이 함께 눌렸나」를 정식 시험 항목으로**」(`docs/3전략_고도화_계획_쉬운설명_2026-09-05.md` ⑧) ⇒ **인쇄만 → 주 검정 승격**(계획서 §7 결정 16).

### 3-1. 🔴 절단 자릿수 = **KSIC 2자리** (동결) — 길이가 고르지 않기 때문

`induty_code` 길이 실측 **3자리 1,070 · 4자리 300 · 5자리 1,186**(메모리 `reference-ksic-industry-not-usable-for-theme.md` 2026-08-07 · 계획서 §3-(c) 2026-09-05 재확인 · **길이 <3 은 0건**).
⇒ **절단 규칙(동결)**: `sector_key = left(ksic_code, 2)`. **길이 < 2 이거나 앞 2자가 숫자가 아니면 그 (종목, 날짜)는 fail-closed 제외**하고 **건수를 인쇄**한다(설계 스펙 `docs/superpowers/specs/2026-09-06-sector-data-design.md` §3.2 `labels_for` 규칙 승계).
🔴 **태쏘 `SEC-D1` 은 N=3 이었다. 이 문서는 2자리다 — *「문턱만 옮기고 «용도»를 안 옮기면 그건 다른 규칙이다」***(태쏘 `PREREG_SECTOR_COMOVE.md` §2-2 인용 `PREREG_RANKING.md` §6). 용도가 다르므로 **더 넓은 칸**을 쓴다: 메모리 확정분 — *「KSIC 는 「대장주/테마」엔 부적합, 단 **「같은 섹터가 함께 눌렸나」**에는 쓸 수 있다」*. 실측 키 공간 **ksic2 = 61개**(설계 스펙 §3.2) ⇒ 백분위 해상도 **1/60 ≈ 1.67%p** — 판정문에 병기한다.

### 3-2. 측정자 (동결) — `SEC-M1` 을 «아래»로 뒤집는다

```
P(D,s)    = { j ∈ 그날 base_filter 통과 집합 : left(ksic(j),2) = left(ksic(s),2) } \ {s}   # 🔴 자기 제외
r_j       = close_j(D)/prev_close_j(D) − 1        # adj_factor 를 가격에 곱하지도 나누지도 않는다
med_k     = median{ r_j : j ∈ P(D,s) }
rank_down = 자기 섹터 제외, med 가 «작거나 같은»(≤) 다른 섹터 수      # 동률 전부 위로 = 보수적
sec_down  = 100 × (G − 1 − rank_down)/(G − 1)     # G = 그날 n_members≥1 인 ksic2 섹터 수 · G<2 면 측정 불가
```
`sec_down` 이 **클수록 그날 그 섹터가 «함께 눌렸다»**. 부호만 뒤집었고 공식은 설계 스펙 §3.2 의 `rank_x`/`pct_x` 와 같다.

| Arm | 조건 |
|---|---|
| **`Ps⁺`** | `P0` ∧ `sec_down ≥ 50` (그날 섹터 **중앙보다 더 눌린** 섹터의 구성원) |
| **`Ps⁻`** | `P0` ∧ `sec_down < 50` |

🔴 **50 은 「중앙값」이지 고른 문턱이 아니다** — 자유모수 0. 🔴 **동료 수 `|P(D,s)| < 3` 이면 측정 불가**(계획서 §3-(c) 「집단 N ≥ 3」) → 두 arm 어디에도 안 넣고 **건수 인쇄**. `G < 2` 도 같다.
🔴 `sector_daily_stats.pct_median` 은 **「전원」 통계**라 그대로 못 쓴다 — 설계 스펙 §3.6 소비자 계약대로 **`fn_sector_map_as_of(D)` 로 라벨만 받고 `daily_prices` 로 자기 제외 재계산**한다. `sector_daily_stats` 는 **대조 인쇄용**으로만 병기.

### 3-3. 🔴 이 축의 «천장»과 소급 라벨 (값을 보기 전에 적는다)

### 5-2. N1 (동결) — 🔴 **N1 문턱과 Holm 문턱은 다르다**

각 arm `A` 에 대해 **`A > R_P[A] 100시드 중 96개 이상`**(🔒 계획서 §7 결정 0 = (나) **96/100**). 단측 순열 `p = (1 + #{R ≥ A})/101`.

| 단계 | 문턱 | S=100 에서 필요한 「R 초과 수」 |
|---|---|---|
| **N1**(arm 자격) | 96/100 | **≥ 96** (p ≤ 5/101 = **.0495**) |
| **Holm 1단계**(m=2) | α/2 = **.025** | (1+k)/101 ≤ .025 ⇒ k ≤ 1 ⇒ **≥ 99/100** |
| **Holm 2단계**(m=1) | α = **.05** | k ≤ 4 ⇒ **≥ 96/100** |

🔑🔑 ***N1 성립이 곧 「가족 보정 후 유의」가 아니다.*** 두 주 검정이 **둘 다** 성립하려면 **더 강한 쪽이 99/100 을 넘어야 한다.** 셋 다 판정문에 인쇄한다. 시드 정합(REGISTRY `S ≥ 20m−1`): m=2 ⇒ 필요 **39** ≤ **S=100** ✅ (문서 1 이 걸린 구조를 이 문서는 피한다).
🔴 **기준선 `P0` 도 같은 검정을 받는다.**

### 5-3. 🔑 주 검정 — **2개** (계획서 §7 결정 16 · 문서 «안»에서 Holm m=2)

**계열 정의(동결)**: `E₁ = {Pd3, Pt1}`(원저작형 — 깊고 신선) · `E₂ = {Pd1, Pt3}`(반대형 — 얕고 늙음). `Pd2`·`Pt2` 는 **돌리되 주 검정에 안 넣는다**(N1 은 인쇄).

**주 검정 ① — 깊이·기간** (위에서부터 처음 성립하는 것을 채택 · 라벨은 상호배타·전부 덮음)

| 순서 | 조건 | 결론 |
|---|---|---|
| 1 | `min(E₁) − max(E₂) ≥ ε` **∧** `E₁` 두 arm 모두 N1 | **(가) 깊고 신선한 눌림이 정보다** |
| 2 | `min(E₂) − max(E₁) ≥ ε` **∧** `E₂` 두 arm 모두 N1 | **(다) 반대다 — 얕고 늙은 눌림이 낫다** |
| 3 | `max(격자 6) − min(격자 6) < ε` | **(마) 구별 불가 — 격자가 성적을 안 가른다** |
| 4 | 그 외 | **(나) 깊이·기간은 정보가 아니다**(차이는 있으나 라인 검정을 못 넘었다) |

**주 검정 ② — 섹터**: `Ps⁺ − Ps⁻ ≥ ε` ∧ N1(`Ps⁺`) ⇒ **(가-S) 섹터 동조는 정보다** / `Ps⁻ − Ps⁺ ≥ ε` ∧ N1(`Ps⁻`) ⇒ **(다-S) 반대다** / `|Ps⁺ − Ps⁻| < ε` ⇒ **(마-S) 구별 불가** / 그 외 ⇒ **(나-S)**.

🔴 **계획서 §3-(c) 의 원안(`min(격자 전체) − P0 ≥ ε` · `Ps − P0 ≥ ε`)을 채택하지 않았다.** `Pd1..3` 과 `Pt1..3` 은 각각 `P0` 의 **분할**이고 `Ps⁺∪Ps⁻ = P0` 이므로 **`P0` 가 그 사이에 오는 것이 (선택 효과를 빼면) 산술적으로 강제된다** ⇒ `min(격자) − P0 ≥ ε` 는 ***거의 원리적으로 불성립***이다. `ma5/PREREG.md` §5-2 가 *「항등식이 만든 부호 일치」*로 금지한 형태의 이면이다.
🟢 **원안의 값도 잃지 않는다** — `min(격자) − P0` 와 `Ps⁺ − P0` 를 **보조 인쇄**(판정 언어 금지)로 함께 낸다. ⬜ **§10-① 사장님 결정 항목.**

### 5-4. 다중검정 · 가족 FWER
