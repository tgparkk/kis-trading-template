| **`p < 0.05` 비율(= 1종오류율)** | **5.0%** | **6.0%** (12/200) |
| `p < 0.20` 비율 | 20.0% | **18.0%** |

⇒ 🟢 **1종오류율이 명목 5%와 어긋나지 않는다**(200 표본에서 SE ≈ 1.5%p) ⇒ **귀무 구현이 보정돼 있다.**

⚠️ **그런데 `p` 평균 0.548 은 0.5 가 «아니다» — 이것도 적어 둔다.**
`U(0,1)` 이면 평균 0.5 · SE = `(1/12)^½/√200` ≈ 0.0204 ⇒ **`z ≈ 2.36`** 으로 유의하게 높다.

- **원인 추정**: `p` 를 **`P(귀무 ≥ 관측)`** 로 «등호 포함» 계산하고 `m_rank` 는 **이산**이라,
  동률이 전부 `p` 를 **키우는** 쪽으로 들어간다(이산 분포에서 표준적인 보수적 편의).
- **방향**: 🟢 **보수적이다** — `RNK-N1` 통과가 «더 어려워지는» 쪽이므로 가드를 느슨하게 만들지 않는다.
- **영향**: 우리가 실제로 쓰는 것은 **5% 꼬리**뿐이고 거기서는 실측 **6.0%** 로 명목과 정합이다.
- 🔑 ***그래도 「평균이 0.5 다」라고 쓰지 않는다 — 안 그렇다.*** 「꼬리가 맞다」와 「분포 전체가
  균등하다」는 다른 문장이고, 이 검사가 보증하는 것은 **앞쪽뿐**이다.

🔑 **계열 규칙 등재 후보**: ***「관측」과 「귀무」를 같은 시드의 «다른» 생성기로 만들지 말 것 —
얽혔는지 확인할 방법이 없다. 그리고 대조군이 한 번 통과했다고 구현 결함이라 단정하지도 말 것 —
「가드가 살아 있다」는 «한 실현»이 아니라 «1종오류율»로 보여야 한다.***

python regen_gate.py             # PASS 확인
