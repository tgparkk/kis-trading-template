## §13. D2 / L4 — 프리셋 변량 «첫» 관측 (판정 아님)

- 혜인 003010 · 프리셋 **`사분위수 Q1~Q3`** — 4개 글 통틀어 `HDR 60%` 가 아닌 «첫» 건.
- D2 는 *「그 건의 `h_max` 가 그 숫자 방향으로 움직인다」* 를 묻는다 ⇒ `h_max` 를 재려면 `P` 가 있어야 한다.
- 혜인 feasible set = **0구간** ⇒ **⛔ `h_max` 측정 불가**
- L4 는 *「그 건의 `b_last`(전 차수 체결 시 DD)가 그 숫자 방향으로」* — 혜인은 **2차**(전 차수 체결 아님) ⇒ `b_last` 가 아니라 `b2 <= DD < b3` 만 준다.
- 혜인 `DD(창A)` = 1 - 6,150/7,700 = **20.13%** ⇒ `b2 <= 20.13` · `b3 > 20.13`
- ⇒ 🟡 **D2/L4 「관측 시작」 — n=1, 판정 없음.** 그리고 **첫 변량 관측이 하필 복원 불가 건**이다.
