## §8. 모호 지점 (양쪽 인쇄 · 어느 쪽도 규칙으로 고르지 않았다)

1. 🔴 **삼양의 `frac_in`·«측도가중» `b₁` 이 post5 보존값에 없다.** 두 통계량은 `P6-L1'`·`P6-L2'`(§3-4)가 **post6 에서 처음 정의**했고 PD-12 는 **재계산 금지**다.
   ⇒ `P6-L1'` 은 **(가)·(나) 분모가 같아지고**(신규 3건 · 「누적 정의 의존」 없음), `P6-L2'` 는 **「범위중점 대입(정의 혼합)」과 「제외」 두 갈래를 병기**했다. **네 갈래가 같은 결론이라 판정은 안 갈렸다.**
2. 🔴 **⛔ 조건 ②(*「feasible 이 빈 집합」*)가 «건 단위»인지 «분모 단위»인지 문언으로 갈리지 않는다.** post5 의 단일 건 문맥에서 쓰인 문장이다. **주 = 건 단위** · **⛔ = 분모 단위** 를 나란히 인쇄했고, ⛔ 읽기가 **가설 A 에 유리한 방향**이라는 것을 자기신고했다. `P6-L1'`·`P6-L2'`·`Q1-R3` 셋이 이 모호에 걸린다.
3. 🔴 **`BUY-L5` 의 정의역** — L5 문언은 *「신규 건 중 되밀린 건」*, `REC-Z4` 는 *「`first_only` 건이 나오면 즉시 판정」*. **두 정의역을 나란히 인쇄**했다(둘 다 ⛔ 라 결론 동일).
4. 🔴 **`P6-L1'-N` 의 창에 등록일 `D` 자신이 포함된다**(`[D−19, D+4]` 문언 그대로). 귀무 비율에 등록일이 `1/24` 만큼 섞인다. 8.5% 수준이라 결론에 영향은 없지만 적어 둔다.
5. 🔴 **최소 n 게이트를 동결 문언 그대로 읽었다** — `P6-L-누적` **3건**(또는 `REC-Z4` 발동 시 즉시). **「측정 가능 건 3건 이상」이라는 새 문턱을 만들지 않았다.**
