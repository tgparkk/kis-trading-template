## §A. 매수 타이밍 — 등록일 «몇 시»에 샀나

`PREREG_BUYLADDER.md` 가 남긴 질문: 1차 매수가 **등록 즉시(추격)**인가 **밴드 대기(눌림)**인가.
논리 제약(`b₁ ≤ 2.47%`)은 즉시 쪽을 시사하지만 **구분은 못 했다.** 분봉이 그걸 가른다.

**통계량** (새 자유도 없음 — 전부 기존 정의 재사용)
- `P` 후보 = `solve_common_band.feasible_P`(잔차 ≤ 0.025%p, gross). 그대로.
- 각 `P` 에 대해 등록일 분봉에서 `low ≤ P ≤ high` 인 **첫 시각** `t(P)`.
- 건의 통계량 = feasible set 전체에 대한 **`t(P)` 의 중앙값**.
- `t_high` = 등록일 **고가가 처음 찍힌 시각**.

**예측 (동결)**
- **N1**: `P` 가 등록일 분봉에서 도달 가능한 건 — **7건 중 5건 이상**.
  (위반이면 *「등록일에 샀다」*가 무너진다 ⇒ §A 전체 기각)
- **N2 (핵심)**: `t(P) < t_high` 인 건이 **과반**.
  🔑 ***올라가는 도중에 샀으면 고가보다 «앞», 눌림을 기다렸으면 «뒤»다.*** 자유도 0 의 이분법.
- **N3 (반증축 · 필수)**: `t(P) < t_high` 는 **`P` 의 당일 위치가 강제**할 수 있다
  (P 가 고가 근처면 앞이 강제된다). 통제: 같은 날 호가격자에서 `P'` 를 균등 추출한
  **귀무 20,000**을 만들어 같은 비율을 잰다. **관측이 귀무 백분위 5% 안에 들지 못하면
  판별력 없음 ⇒ N2 지지를 취소한다.**
- **N4 (기술)**: `t(P)` 중앙값의 시각 분포, `(P−저가)/(고가−저가)` 를 건별로 기록. 예측 없음.

## §B. 매도 타이밍 — 분봉 해상도로 순서를 다시 가른다

`PREREG_SELLTIMING.md` §2 의 질문을 그대로 옮긴다: 비증가 수열이 **시간순**(하락 추종)인가
**역순**(목표가 사다리)인가.

**통계량**: 일봉을 분봉으로 바꾼 것 외에는 `PREREG_SELLTIMING.md` §3 과 동일.
- `Dᵢ` = `{분봉 m : low_m ≤ Sᵢ ≤ high_m}` (창 = 등록일 ~ 글 발행일, 거래정지일 제외)
- 시간순(비감소) / 역순(비증가) 배정 존재를 그리디로 판정.

**예측 (동결)**
- **S1**: 시간순 배정이 가능한 건 **7건 중 5건 이상**.
- **S2 (반증축 · 필수)**: **시간순 건수 − 역순 건수 ≥ 2** 여야 지지.
  🔴 일봉판이 (7−7)=0 으로 기각됐다. **같은 기준을 미리 못박는다** — 사후에 완화하지 않는다.
- **S3**: 본전 레그(`|ret| < 1%`)가 시간순 배정의 **마지막**. 해당 건 전부.
- **S4 (기술)**: 첫 매도 시각 · 마지막 매도 시각 · 총 소요(분·거래일) · 레그 간 간격.

🔴 **일봉판에서 6/7 건이 「하루 안」이었다.** 분봉에서 그 하루의 **가격 경로가 고정**이므로,
시간순이 성립하려면 그 안에서 가격이 실제로 내려가야 한다. **여기서 갈리지 않으면 이 축은
7건으로는 못 푼다**고 적고 종결한다.
