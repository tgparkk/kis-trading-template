### 1-2. 무엇이 같이 무너졌나

## §3. 후보 앵커 — **셋 · 상호 배타** (채택은 정확히 하나)

🔴 **네 정의 전부 이미 동결된 것의 재사용이고, 새 자유도는 0 이다.** 새 창·새 문턱을 만들지 않았다.

### `A1` — 전방 전창 최고 (forward running high)

```
H₁ = SELECT max(high) FROM daily_prices
      WHERE stock_code = %s AND date BETWEEN D AND END
```
🔑 이건 `run_reconstruct_post6.py:443-444` 가 **이미 `HI` 로 계산하는 값 그 자체**다 — 새 코드 0줄.
- 성질: `h ∈ [0, 1]` 이 **정의상** 보장된다. `DD ≥ 0` 도 정의상이다.
- 🔴🔴 **그 대가로 `ANC-P1` 이 항등(0/n)이 된다** — §5-3 항등 조항이 여기 걸린다.
- 🔴 **사후 정보를 쓴다**: `H₁` 은 발행일까지 봐야 확정되므로 **저자가 매도 시점에 몰랐던 값**이다.

### `A2` — 창5 최고 (cycle-truncated running high)

```
H₂ = max(high) over 창5 = [D, D+4거래일]      -- 거래일 창, 등록일 포함
```
거래일 창은 `run_reconstruct_post6.py:143-151` 의 `win_bars(cur, code, D, back=0, fwd=4)` 가 주는 봉의 `high` 최댓값.
창5 는 `PREREG_LADDER_TRANCHE.md` §4-2 가 **이미 동결한 창**이다(*「창5 로 못 박는다」*) — 이 문서가 고른 창이 아니다.
- 성질: 사후 정보가 **최대 4거래일**로 한정된다(저자가 주간 회고를 쓰는 시점과 같은 지평).
- 🔴 **창5 절단 건**(발행일까지 4봉 미만)은 `PREDECISION_2026-09-04_post6.md` **PD-11** 규정을 그대로 승계한다:
  분모에 넣고 · `P6-WIN5_TRUNC` 플래그·건수·봉수 의무 인쇄 · 제외 민감도 병기.

### `A3` — 후방 20봉 최고 (`PREREG_Q1_V2.md` §2 `H6` 승계)

```
H₃ = SELECT max(high) FROM (SELECT high FROM daily_prices
       WHERE stock_code = %s AND date <= D ORDER BY date DESC LIMIT 20) t
```
🔑 이건 `run_reconstruct_post6.py:153-160` 의 `dd_h(cur, code, d0, d1, k)` 가 `k = 20` 일 때 계산하는 `H` **그대로**다 — 새 코드 0줄.
`PREREG_Q1_V2.md` §2 표의 **`H6` = `max(high) over [D−19, D]`** 와 같은 값이다.
- 성질: **사후 정보 0** — 등록일 종가 시점에 확정된다. 「저자가 아는 값」 계열의 유일한 후보.
- 🔴 붕괴 원인이 *「등록일 «뒤»의 상승」*이므로(§1-1 의 아이티센 +28.83% · 원익 +31.04%)
  **이 후보는 `ANC-P1` 을 못 고칠 가능성이 높다** — 그게 §4 의 예측이다.

### 상호 배타성 · `A0` 의 지위

- **채택 후보 = `{A1, A2, A3}`. 정확히 하나를 채택하거나, 하나도 채택하지 않는다.**
- **`A0` 는 대조군으로만 남는다**(채택 후보가 아니다). post6 에서 이미 무너졌고,
  🔑 ***무너진 것을 다시 후보에 넣으면 「기각을 무르는」 동작이다***(`PREREG_WEIGHTED_RECON.md` §5-3 6번 관용).
- 🔴 **혼합 금지**: 「`h` 는 `A1`, `DD` 는 `A3`」 같은 조합을 쓰지 않는다. 앵커가 갈리면 `REC-Z3` 이 처음 잡아낸
  *「같은 앵커 가정에서 함께 무너진다」*는 진술의 대상이 사라진다.

### 4-1. `ANC-P3` 의 `DD` 정의 (동결)

```
DD(X) = 1 − L₅ / H_X            -- L₅ = min(low) over 창5 [D, D+4거래일]
```
창5·동률 대역 `δ = 1.0%p`·통계량 `V`(= `N_i < N_j` 이면서 `DD_i ≥ DD_j` 인 쌍의 수)·
단측 `p = P(V ≤ V_obs)` 는 전부 **`PREREG_LADDER_TRANCHE.md` §4-2 ~ §4-4 그대로**다.
🔴 **`δ` 도 `V` 도 이 문서에서 고치지 않는다** — 앵커만 바꾼다. 그래야 「앵커가 원인이었나」가 잰다.

### 4-2. 예측의 방향을 «먼저» 자기신고한다

- 🔑 `ANC-P1`·`ANC-P2` 에서 **`A2` 만 「고쳐진다」 쪽**에 걸었다. 근거는 산술이다 —
  `A2` 는 등록 후 4거래일 안의 최고가를 천장으로 삼으므로, 그 뒤의 상승은 천장을 뚫지 못한다.

- 🔑 `A3` 에는 **「고쳐지지 않는다」**에 걸었다. 🔴 ***이 예측이 맞으면 `A3` 는 탈락한다*** —

## §5. 판정 규칙 · 채택 규칙 (동결)

### 5-1. 채택 최소 조건 — **전부 AND**

후보 `X` 가 채택되려면 셋을 «전부» 만족해야 한다.

1. **`ANC-P1`**: post7 신규 건에서 `Z3(X) < 1/2`.
2. **`ANC-P2`**: post7 신규 건에서 `h_obs(X) ≤ 1` 인 건이 **≥ 2/3**.
3. **`ANC-P3`**: 무작위 앵커 대조군 `R`(§7-3 · 시드 100개) 중 `V(R_j) ≤ V(X)` 인 것이 **0개**
   ⇒ 순열 `p = 1/101 = .0099 < ` Holm 1단계 문턱 **.0167**(§7-1 산술).

### 5-2. 채택 결과의 세 갈래

| 조건을 다 만족한 후보 수 | 처리 |
|---|---|
| **정확히 1** | 그 후보를 **채택**한다. `HDR-` `h` 축 · `LAD-` `DD` 축 · `BUY-L5` 를 그 앵커로 **재개**한다. |
| **2 이상** | 🔴 **채택하지 않는다.** 다음 글로 미룬다. 🔑 ***둘 중 하나를 값을 보고 고르면 그게 사후적합이다.*** |
| **0** | 🔴🔴 **앵커 기반 축 전면 폐기**를 사장님께 올린다 — `HDR-D1`·`HDR-D2`·`LAD-T1`·`LAD-P2`·`BUY-L5` 종결. |

🔴 **재개는 자동이 아니다.** 채택이 결정돼도 `REC-Y3`(복원 중단)이 여전히 발동 중이면
`BUY-L5` 는 **열리지 않는다** — 그 축은 복원 `P` 를 쓰기 때문이다(§1-3).
🔒 결정 대기(④`P6-L-대칭` 기각 후 처리) — ④가 「`PREREG_BUYLADDER` 계열 종결」로 결정되면
**`BUY-L5` 재개 조항은 자동 소멸**한다. 이 문서는 그 결정을 앞질러 가지 않는다.

### 5-3. 🔴🔴 항등 조항 (`ANC-N2`) — 위반하면 산출물 무효

- **정의상 참인 자리를 「충족」으로 세지 않는다.** `A1` 의 `ANC-P1`(0/n)·`ANC-P2`(1) 는
  산출물에 **「항등 — 표 없음」**이라고 인쇄하고, §5-1 의 조건 충족 개수에 **넣지 않는다**.
- ⇒ 그 결과 **`A1` 은 `ANC-P3` 하나만으로 채택 여부가 결정된다.** 이 비대칭을 산출물에 매회 명시한다.
- 🔑 ***`h ∈ [0,1]` 을 정의로 보장하는 앵커는 「틀이 성립한다」를 증명한 것이 아니라 「측정을 포기한 것」이다.***

### 5-4. 소급분(post1~6)의 지위

- **소급 계산은 «의무»다**(안 하면 예측의 크기를 못 잰다) — 그러나 **채택 근거로 쓰지 않는다.**
- 산출물에 *「소급 = 탐색 · 채택은 post7 열로만」*을 **매 표마다** 적는다
  (`PREREG_Q1_V2.md` §0 관용 그대로: *「같은 표본에 정의를 바꿔 다시 돌리는 것은 정의상 사후적합」*).

## §7. 귀무 · 시드 (동결)

### 7-1. 검정 수와 시드 — 산술을 인쇄한다 (`concept_axes/REGISTRY.md` 시드 표 승계)

- **주 검정 `m` = 3** (`ANC-P1` · `ANC-P2` · `ANC-P3`).
- Holm 1단계 문턱 = `α/m` = `.05/3` = **`.0167`**.
- 순열검정의 최소 `p` = `1/(S+1)`. `1/(S+1) ≤ .0167` ⇒ **`S ≥ 59`**
  (= `REGISTRY.md` 규칙 `S ≥ 20m − 1` = `20·3 − 1` = **59** · 권장 60).
- ⇒ **채택 `S = 100`** (여유 · 최소 `p` = `1/101` = `.0099`). `REGISTRY.md` 문서 5(minervini `B`)의 100 과 같은 관용.
- 🔑🔑 ***시드 수와 보정 방식을 «따로» 고르지 않았다*** — `m` 을 §4 에서 확정한 «직후» 이 산술로 정했다.
- 🔴 **결과를 본 뒤 `S` 나 `m` 을 바꾸지 않는다.** (`REGISTRY.md`: *「문서 1 은 재실행하지 않는다」* 전례)

### 7-2. `ANC-P3` 순열 귀무 — **크기 정합 + 층화**

- **재배정**: 차수 다중집합 `{N_i}` 를 낙폭 벡터 `{DD_i}` 에 무작위 재배정
  (`PREREG_LADDER_TRANCHE.md` §4-4 그대로 · 새 정의 아님).
- 🔴 **크기 정합**: 귀무 표본은 관측과 **같은 크기**다 — 층 안 건수를 보존한다.
- 🔴🔴 **층화(신설 · 이 문서의 유일한 추가 자유도)**: 재배정을 **글(post) «안에서»** 한다.
  근거를 결과와 무관하게 먼저 적는다 — 글마다 종목 수(3~12)와 시장 국면이 다르고,
  글을 섞어 재배정하면 **「글 사이 차이」가 「차수 차이」로 새 들어온다**.
  🔑 ***계열 교훈 그대로: 「귀무가 반보수적이었다(실제 1종오류 17~32%)」의 원인이 크기 부정합과 층화 누락이었다.***
  🔴 **층화 없는 갈래도 의무 민감도로 병기**한다. 두 갈래가 갈리면 ⇒ `ANC-N4` 발동(선언 금지).
- **반복수**: 서로 다른 배정이 **≤ 200,000** 이면 **전수**, 넘으면 **시드 고정 200,000 표본**.
  시드 = **`NULL_SEED = 20260815`** — `run_ladder_tranche_post6.py:26,61` 값 **그대로**. 🔴 새 시드를 만들지 않았다.

### 7-3. 무작위 앵커 대조군 `R` (판별력 바닥)

- `H_R(i, j)` = 창 `[D, END]` 안의 **무작위 한 봉의 `high`** — 건별로 뽑는다.

  ⇒ 🔴 **`ANC-` 축의 DB 지문은 post7 판정 «시점»에 그때 값으로 박는다.** 이 문서는 앵커 «정의»만 동결한다.
- 🔑 ***DB 가 바뀌었으면 산출물은 스크립트와 일치해도 「낡았다」*** (`regen_gate.py` 자기 문언).

🔒 결정 대기(⑦`FROZEN_STALE` 3건) — ⑦이 「(나) 재기준선」으로 결정되면 위 §9-1·§9-2 표는
**그 재기준선 시점 값으로 다시 박아야 한다**. 이 문서는 (가) 유지 전제로 적혀 있다.

## §11. 등재 (`regen_gate.py`)

- 이 문서는 **사람이 쓴 문서**이므로 `PAIRS`(스크립트 산출물) 대상이 **아니다**.
  `MANUAL_DOCS` 에 **`PREREG_ANCHOR_REDESIGN.md`** 를 등재해야 한다(G-1 존재 검사 대상).
  전례: `PREREG_POST6.md`·`PREREG_RANKING.md`·`PREREG_WEIGHTED_RECON.md`·`PREREG_SECTOR_COMOVE.md`.
- 🔴 **등재는 파일이 «있는» 순간에 한다** — 이름만 먼저 박으면 G-1 이 「없는 파일」로 상시 FAIL 해서
  진짜 가드가 죽는다(`regen_gate.py` MANUAL_DOCS 주석의 `FREEZE_SECTOR` 전례).
- 🔴🔴 **그러나 이 라운드는 `regen_gate.py` 를 «건드리지 않았다».** 그 파일은
  `FREEZE_RANKING_2026-08-31.md` §2 · `FREEZE_WRC_2026-09-02.md` §2 · `FREEZE_SECTOR_2026-09-03.md` §2-4
  **세 동결 표에 md5 가 박혀 있는 동결 산출물**이기 때문이다.
  ⇒ **등재는 그 파일을 소유한 레인(최종 레인)이 별도 커밋으로 수행한다.** 여기는 그 의무를 «신고»만 한다.
- `ANC-` 측정 스크립트(`run_anchor_redesign.py`, 아직 없다)가 생기면 그때 `PAIRS` 에 등재한다.
  🔴 **C-23 승계**: `PAIRS` 값에 **인자를 포함**해 적는다(`"run_anchor_redesign.py --mode post7"`) —
  인자 없이 부르면 다른 모드가 곁다리로 동결본을 덮어쓴다.
  🔴 **C-24 승계**: `sha()` 는 줄끝을 LF 로 정규화해 잰다 — §9 의 md5 표(작업트리 바이트)와 **잣대가 다르다.**
  두 값을 같은 표에 섞어 적지 않는다.
  🔴 **ART_DIRS**: `ANC-` 가 디렉토리 산출물을 만들면 `ART_DIRS` 에 선언한다 — 루프 «전체» tripwire 가
  곁다리 덮어쓰기를 잡는 «유일한» 축이다.

## §13. 미리 적어두는 한계

- 🔴 **소급(post1~6)은 탐색이다.** 같은 표본에 새 앵커를 적용해 나온 수는 **증거가 아니다.**
  진짜 검정은 post7 열 하나뿐이고, 그 표본은 **아직 0건**이다.
- 🔴 **`ANC-P3` 의 검정력이 낮을 수 있다.** post6 에서 쌍을 41 → **161**(3.93배)로 늘렸는데
  `p` 는 0.5160 → **0.4914** 로 제자리였다(`INTAKE_2026-09-04_post6.md` §6 #21).
  ⇒ ***쌍을 늘려도 안 움직이는 축이라, 앵커를 바꿔도 안 움직일 수 있다.*** 그때 답은 `ANC-N1` 발동(판별력 없음)이다.
- 🔴 **`h_obs` 는 `close` 로 재는 하한 검사다.** 저자의 매도는 장중가에 체결되므로
  `h_obs ≤ 1` 이라고 해서 실제 매도가가 앵커 아래였다는 뜻은 아니다.
  ***복원 `P` 로 재는 진짜 `h_max` 는 `REC-Y3` 중단 때문에 못 쓴다*** — 이 대체가 이 문서의 가장 큰 약점이다.
- 🔴 **`A2` 의 창5 는 `LAD-` 축에서 «위반 4쪽»이라는 걸 알고 고른 창이다**
  (`PREREG_LADDER_TRANCHE.md` §4-2 자기신고 승계). 앵커로 옮겨 써도 그 편향이 사라지지 않는다.
- 🔴 **`END` 가 글 발행일이라 후보마다 창 길이가 다르다** — 등록이 발행 직전이면 창이 3~4봉뿐이다.
  창5 절단 처리는 PD-11 승계지만, **`A1` 의 창은 절단 개념 자체가 없다**(창이 곧 `[D, END]`).
  ⇒ 🔴 `A1` 과 `A2` 는 **짧은 창에서 같은 값이 된다**. `ANC-N1` 이 그걸 잡는다.
- 🔴 **저자가 앵커를 안 쓸 수도 있다.** `HDR 60%` 라는 프리셋 이름이 「낙폭의 60% 되돌림」이라는
  해석은 `PREREG_HDR.md` §2 의 **가설**이지 저자 진술이 아니다. 세 후보가 다 실패하면
  그 가설 자체가 틀린 것이고, §5-2 의 「0개 → 전면 폐기」가 그 경로다.
