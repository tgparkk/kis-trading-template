## §1. 왜 이 축만 값을 모르나

기전은 안다 — 분할매도 → 미체결 물량 다음 차수 합산 → **본전(평단 지정가) 청산** → 안 되면 분할손절.
복원이 이걸 독립 확인했다(매드업 7,410→7,440 · 빛과전자 2,945→2,955 = 본전).

**모르는 것은 사다리의 레벨이다.** `HDR 60% / 표준형` 이 어떤 가격으로 번역되는지 안 풀었다.

## §2. 가설 — 저자가 숫자를 이름에 적어놨다

저자의 두 트랙 표(`METHOD.md` §6)에서 **청산 = 「저점 대비 반등폭 HDR 구간」**이다.
프리셋 이름이 **`HDR 60%`** 이므로, 매도 목표가 **낙폭의 60% 되돌림**일 것으로 예측한다.

정의 (전부 이미 고정된 것만 재사용 — 새 자유도 없음):

- `H` = **등록일 고가** (`PREREG_Q1_V2.md` §2 의 v2 앵커)
- `L` = 등록일~사이클 종료 구간의 **최저 저가** (`PREREG.md` §3 의 `DD` 에 쓴 그 값)
- `hᵢ` = `(Sᵢ − L) / (H − L)` — 매도가를 **저점 대비 반등폭**으로 옮긴 값
- `Sᵢ` = `P·(1+rᵢ)` · `P` 는 `reconstruct_prices.py` 의 feasible set (잔차 ≤ 0.025%p, gross)

## §3. 예측과 결정규칙 (동결)

- **H1 (핵심)**: 각 건에서 **최고 매도가**의 `h_max` 가 **0.60 ± 0.10** 에 드는 `P` 가
  feasible set 안에 **존재**한다. → **7건 중 5건 이상**이면 지지.
- **H2**: 여러 건이 **하나의 공통 `h_max`** 로 설명된다 — `b₁` 공동해법과 같은 방식
  (격자 ±0.01, 스케일 보존 귀무). **관측 커버리지의 귀무 백분위 < 5%** 면 지지.
- **H3 (반증축)**: 위 `h` 를 **`HDR 60%` 가 아닌 다른 값**(0.3·0.5·0.8)으로 바꿔도 같은 정도로
  설명되면 **60% 라는 숫자에 판별력이 없다** ⇒ H1 지지를 취소한다.

🔴 **H3 를 반드시 함께 낸다.** *「0.60 근처에 든다」* 는 것만으로는 아무 값이나 들 수 있다.
`METHOD.md` §④ 의 *「경쟁 규칙보다 잘 맞혀야 증거다」* 를 그대로 적용한다.

## §4. 🟢 다음 글 예측 (진짜 검정)

- **D1**: 다음 글에서 프리셋이 **`HDR 60%`** 로 명시된 건의 `h_max` 중앙값이 **0.50~0.70**.
- **D2**: 프리셋 숫자가 **다른 값**(예: HDR 40%)인 건이 나오면, 그 건의 `h_max` 가
  **그 숫자 방향으로 움직인다**. ← 🔑 이게 결정적이다. 지금 표본은 전부 60% 라 **변량이 없다.**

## §5. 미리 적어두는 한계

- 🔴 **`P` 가 구간이라 `h` 도 구간이다.** 「존재한다」는 약한 주장이다.
- 🔴 **표본 전체가 `HDR 60%` 한 값**이라 *「60 이라는 숫자가 원인」*임을 이 표본으로는 못 보인다.
  D2 가 나오기 전까지 **인과 주장 금지.**
- `L` 이 사이클 종료 «이후» 더 내려갔을 수 있다(우리 창은 글 발행일까지다).
- 분할손절 건(모나미)은 기전이 달라 **제외**한다.
