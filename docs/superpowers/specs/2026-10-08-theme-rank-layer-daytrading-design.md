## 1. 목적과 범위

- **목적 1(수익)**: 빈 보유 자리를 채울 후보의 순서를 테마 정보로 바꿔 거래당 수익을 올릴 수 있는지 판정한다.

## 2. 출발점 사실 (2026-10-08 실측)

### 2-1. 전략이 실제로 순위를 쓰는 자리
- 후보 = 전일 일봉 종가 ≥ 직전 15봉 고점 ∧ 거래량 ≥ 20봉 평균×2 ∧ 양봉 ∧ 시총 < 5천억 ∧ 거래대금 ≥ 10억. 현재 순위 = 거래량 배수.
- 다음 날 전일 종가 +3% 밴드 안이면 매수 · 하루 매수 5 · 보유 자리 K=10 · ±10% · 최대 10거래일.
- 🔑 **하루 5개 한도는 사실상 안 걸리고 자리 10개가 걸린다**: `freq_scenarios/freq_table.csv`(research/candidate-ledger) daytrading 전체 구간 `N=5,K=현행` 1,412건 vs `N=∞,K=현행` 1,416건 · 하루 평균 매수 2.3. ⇒ 순위가 실제로 정하는 것은 **그날 빈 자리 2~3개를 누가 채우나**.
- 조건 통과 후보는 원장 기준 하루 평균 29.6(중앙 26 · 최대 117 · 20 초과일 397/617). `screener_snapshots` 저장 명단 기준으로는 하루 15.6(2026-06-05~10-07 · 81일).
- 라이브는 상위 20 → 안전필터 → 10 풀 → 밴드 안에 먼저 드는 순(`core/candidate_selector.py:1060-1169` · `strategy.py:84-86,274` · `core/trading_decision_engine.py:426-442`).

## 4. 신호 정의 🔒(사전등록에서 그대로 동결)

### 4-1. 1차 신호 = 테마 돌출도 `S`
D = 후보의 scan_date(돌파한 날). 모든 가격은 KRX 일봉(`daily_prices`) · 수정 처리 규칙은 후보 원장과 같게(kis-template 규칙: `adj_factor` 를 가격에 곱하지 않는다).

1. 유니버스 `U_D` = D 와 D−1 종가가 모두 있는 종목(지수 의사티커 6개 제외).
2. `r_i = close_D / close_{D−1} − 1` · 시장 `m_D` = `U_D` 동일가중 평균 · 초과수익 `e_i = r_i − m_D`.
3. 「튄 종목」 = `e_i ≥ +0.05` · `p0_D` = `U_D` 중 튄 종목 비율.
4. 후보 c 의 적격 테마 T(§4-2)마다 동료 `P = (T ∖ {c}) ∩ U_D` · `n = |P|` · `k` = P 중 튄 종목 수.
   `k ≥ 2` 이면 `p_T = P(Bin(n, p0_D) ≥ k)`, 아니면 `p_T = 1`.
5. `m_c` = c 의 적격 테마 수(n ≥ 1 인 것). `p_c = min(1, m_c × min_T p_T)`(테마 수 보정 — 테마를 많이 가진 종목이 유리하지 않게).
6. **`S_c = −log10(p_c)`**. `m_c = 0` 이면 `S_c = 0`(중립 · 「단독 재료」 표식). 주 테마 = `argmin_T p_T`.

설명용 예(그날 `p0` = 3% 가정): 11개 테마에서 동료 10 중 4개 튐 → 우연 확률 ≈ 0.015% → S ≈ 3.8 · 100개 테마에서 동료 99 중 6개 튐 → ≈ 8% → S ≈ 1.1.

### 4-2. 적격 테마
- **검정 창 시작(2024-03-13) 이전에 이미 있던 테마만**. `theme_no` 는 순번이라 생성 시점의 대리값 — 경계 번호 `N_cut` 은 사전등록에서 근거(테마 설명·편입 사유의 날짜 등)와 함께 고정한다(예비 추정: 퀀트 547 · 실전 564 ≈ 2024-08).
- 사건·분류형 테마 제외 목록을 **이름만 보고** 사전등록에 고정한다(후보: 밸류업 계열 3 · 지주사 · SPAC · 신규상장 계열 2 · 계절(여름·겨울) · 코로나19 계열).
- 크기 상한 같은 임의 절단은 두지 않는다(돌출도가 넓은 업종형 테마를 스스로 낮춘다).

### 4-3. 소속표 시점
- 과거 검정: 2026-10-08 스냅샷(run_id 4) 하나를 전 구간에 적용(미래 참조 — §5-7 한계).
- 앞으로: D 의 신호에는 `snap_date ≤ D+1` 중 가장 최근 스냅샷(D+1 07:45 = 09:00 매수 전). 없으면 직전 스냅샷 + 충실도 결함으로 기록.

### 4-4. 방향
양측 검정. 양(+) = 돌출도 높은 후보에게 빈 자리 먼저. 음(−) = 「테마 의존 돌파 → 순위 하향」(실전 고수 예상 방향) — 유의해도 바로 반영하지 않고 별도 앞으로 검증(§5-6).

### 4-5. 인쇄만(판정 언어 금지)
- A: 적격 테마별 동료 동일가중 초과수익의 최댓값(원래 안)
- C: 그날 조건 통과 후보 전체 중 같은 주 테마 후보 수
- B′: 주 테마 소속 전체 안에서 c 의 당일 `r` 순위(1위·상한가 여부)
- A″: 주 테마의 `p_T < 0.01` 연속 일수(1~2일차 vs 3일차 이상)
- 앞으로 구간만: 네이버 `theme_daily.change_rate`(D+1 07:45 스냅샷 = D 의 NXT 마감값)

## 5. 과거 검정 🔒

### 5-1. 표본·체결·결과
- 후보 원장(`research/candidate-ledger` · `backtest/concept_axes/candidate_ledger/`) daytrading 2024-03-13 ~ 2026-09-23 · 617거래일.
- **밴드 재현 체결**(원장의 「다음 날 시가 매수」 대신): 상한 = `close_D × 1.03`(라이브와 같은 호가 반올림). `open_{D+1} ≤ 상한` → 시가 체결 · 아니고 `low_{D+1} ≤ 상한` → 상한가에 체결 · 그 밖 미체결. 하한은 라이브 설정과 같게(현재 없음).
- 청산은 원장 `ledger8/exitsim8.simulate_lot` 규칙 그대로(TP +10% · SL −10% · 최대 10거래일 · 같은 봉 동시 → 손절) · 비용은 `freq_scenarios` 비용 모델 · 결과 = 거래당 순수익률 `ret`.
- **경기장** = 그날 현재 순위(원장 `rank`) 1~20 중 밴드 체결된 후보.

### 5-2. 1차 통계
- 날짜 D 마다 경기장에서 `Spearman(S, ret)` = IC_D. 경기장 체결 후보 < 5 이거나 S 의 서로 다른 값 < 2 인 날은 제외(제외 일수 인쇄).
- `mean(IC_D)` 에 Newey-West HAC t · **lag 11(판정)** · lag 22 병기(판정 일치 표시). 양측 α = 0.05.
- 날짜×테마 이중 군집은 쓰지 않는다(한 종목이 여러 테마 → 정의 불가).

### 5-3. 도구 교정(동결 전 · 결과 수익과 실제 신호를 함께 보지 않음)
- 가짜 테마 신호 400개: 적격 소속표 그대로, 테마×날짜 잡음 `z_{T,D}`(날짜 방향 AR(1) φ = 0.9) → §4-1 의 최댓값·테마 수 보정 구조를 거친 가짜 S → §5-2 통계.
- 합격 = `p < 0.10` 거부율 0.07 ~ 0.13. 불합격이면 lag 11 → 22 → 33 순으로 올려 재교정 · 그래도 불합격이면 400개 가짜 t 의 경험분포로 p 를 보정. 결과를 사전등록에 적고 동결.
- K2(날짜 내 3분위 + 종목 군집 CR1)는 그룹 신호 교정을 거친 적이 없으므로 **판정 도구로 쓰지 않는다**(인쇄만).

### 5-4. 돈으로 확인 — 빈 자리 고정 짝 비교
- 기준선 경로: 현재 순위 · K = 10 · 하루 5 · 보유 중 종목 건너뜀 · 밴드 재현 체결로 시뮬레이션 → 날짜별 실제 매수 수 `f_D`.
- `f_D ≥ 1` 인 날마다 (보유 중 제외 경기장에서) ① 기준선이 산 `f_D` 개 ② S 상위 `f_D` 개(동점 = 현재 순위) ③ 경기장 평균(= 무작위 기대값)의 거래당 `ret` 평균.
- 분해 보고: `Δ_cur = ③ − ①`(현재 순위가 나빠서 생긴 몫) · `Δ_theme = ② − ③`(테마가 보탠 몫). 게이트 = `Δ_theme ≥ +0.5%p`(양의 방향일 때). 무작위 seed 순열은 쓰지 않는다(기대값이 ③ 로 정확히 나옴).

### 5-5. 편향 점검

- 점검: 결과가 확정된 20·40·60거래일. **중단** = 앞으로 구간 `mean(IC) ≤ −1 × 표준오차`. **통과** = 60거래일에 앞으로 구간 IC 의 95% 신뢰구간이 과거 추정치를 포함(모순 없음) ∧ 충실도 게이트 충족. 효과 크기 주장은 하지 않는다.
