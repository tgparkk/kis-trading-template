# 계획2 사전등록 — CNN 선별기 성공 게이트 (결과 보기 전 커밋)

작성 시점: CNN 학습 결과를 **보기 전**. 이 파일과 이후 코드가 어긋나면 이 파일이 옳다.
직전 intraday 워크포워드 사전등록(`c4851f2`)과 같은 계약 — 결과를 보고 기준을 바꾸지 않기 위함.

## 실측 배경 (label_scan, 전체 15개월, 540,025 샘플, 30분 stride)
무조건 진입(전 시점 매수·3거래일 홀드)의 거래당 net(비용 0.21% 후):
3/3 **+0.23%** · 3/5 +0.36% · 5/5 +0.43% · 7/7 +0.54% · 10/10 +0.62% · 15/15 +0.72%.
TP선착 > SL선착(3/3: 44% vs 35%) = **이 기간(2025-04~2026-06) 강세장 상승표류 + 199유니버스 생존편향**.
→ 절대 net은 베타로 이미 양수. **"gross≥0.26%" 원래 기준선은 무의미**(베타만으로 넘음).

## 성공 게이트 (확정) = 메트릭1(베타초과 lift) + 안전장치
워크포워드(확장창 다중 폴드, 각 폴드 학습구간에서만 CNN학습·임계·정규화통계 산출, 다음 폴드서 1회 평가):

각 테스트 폴드에서:
- **base_net** = 그 폴드 무조건(전체 후보) 거래당 net.
- **sel_net** = CNN 점수 상위선별 subset의 거래당 net. (선별 방식·상위비율은 학습구간에서 고정.)
- **lift = sel_net − base_net.**

**주 판정 (전부 만족해야 통과):**
1. lift > 0 인 폴드가 **과반**(예: 7폴드 중 ≥5).
2. **합산(거래가중) lift > +0.10%p.**
3. 합산 **sel_net 절대값도 > 0**(비용 후 실제로 벎; "베타 큰 것만 골라 lift는 양수인데 절대 손실" 차단).

**보조 진단 (판정 아님, 기록만):** 횡단면 IC(일단위 시장평균 제거 후 CNN점수 vs 실현수익 스피어만). 부호·크기 기록.

**사후 조정 금지.** 통과선(≥+0.10%p, 과반, 절대양수)은 지금 고정. 폴드수·상위비율은 학습구간에서만 정함.

## TP/SL 선택
label_scan상 tp/sl 균형·저timeout이 가장 큰 학습신호 → **3x3 또는 3x5 우선**(timeout 21~32%).
넓은 배리어(10x10~15x15)는 timeout 80~92% = 사실상 매수후보유=베타측정이라 선별신호 빈약. 배제.
폴드 학습구간에서 {3x3, 3x5} 중 학습 lift 최대를 선택(평가구간 미사용).

## 접근: PoC 게이트 먼저 (28GB 빌드 전)
1. **PoC**: 소규모(수개월·소량 시점) 이미지셋 + 작은 CNN. **인샘플에서 base 대비 lift>0** 이 나오는지만 확인.
   안 나오면(모델이 base조차 못 이김) 여기서 종료 — 전체 빌드 안 함(예산 스파이크와 같은 규율).
2. PoC 통과 시에만: 전체구간 스트리밍 추출(memmap·전체1회) → 전체 워크포워드 → 위 게이트로 최종 판정.
